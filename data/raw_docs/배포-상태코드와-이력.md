# 배포 상태 코드와 이력 조회

배포 화면에 나오는 상태값은 공통코드로 관리됩니다. 어떤 코드가 무엇을 의미하는지,
이력은 어디서 보는지 정리합니다.

## 배포 상태 코드 (`DEPLOY_CD`)

| 코드 | 단계 | 설명 |
|---|---|---|
| `DEPLOY1000` | 신청 | 배포 신청이 등록된 상태 |
| `DEPLOY1050` | 승인 대기/진행 | 결재선에 올라간 상태 |
| `DEPLOY1063` | TB 배포 완료 | 검증계 반영 완료 |
| `DEPLOY1065` | 운영 배포 대기 | 운영 반영을 기다리는 상태 |
| `DEPLOY1070` | 배포 완료 | 운영 반영까지 끝난 상태 |

목록 화면에서는 이 코드가 아니라 코드명(`deployCdnm`)으로 표시됩니다. 필터로 특정
단계만 골라 볼 수 있습니다.

## 게이트웨이 작업 상태

게이트웨이 연동 작업 자체의 상태는 애플리케이션 내부 열거형으로 관리됩니다.

**배포 작업(`DeployJobStatus`)**

| 값 | 표시 | 의미 |
|---|---|---|
| `STANDBY` | Stand By | 대기 |
| `INIT` | Init | 초기화 |
| `DEPLOYING` | Deploying | 배포 진행 중 |
| `ROLLING_BACK` | Rolling back | 실패해서 되돌리는 중 |
| `DONE` | Done | 성공 |
| `FAIL` | Fail | 실패 |

**일반 작업(`JobStatus`)**

| 값 | 표시 |
|---|---|
| `STANDBY` | Stand by |
| `DOING` | Doing |
| `DONE` | Done |
| `FAILURE` | Failure |

**게이트웨이 결과(`GWResultType`)**

| 값 | 표시 |
|---|---|
| `OK` | Success |
| `FAILURE` | Failure |

**API 작업 종류(`ApiActionType`)**

| 값 | 의미 |
|---|---|
| `CREATE` | 신규 등록 |
| `UPDATE` | 변경 |
| `DELETE` | 삭제 |

**환경(`GwProfile`)**

| 값 | 의미 |
|---|---|
| `TB` | 검증계 |
| `PROD` | 운영 |

## 이력 화면

| 이력 | URL | 내용 |
|---|---|---|
| 배포 이력 | `mvDeployHstAjax.do` | 신청 건의 단계별 변경 기록 |
| TB 배포 이력 | `mvTbDeployHstAjax.do` | 검증계 배포 회차별 결과 |
| 운영 배포 조회 | `mvCbDeployViewAjax.do` | 운영 반영 현황 |
| 검증 이력 | `popVerifiHst` 팝업 | 검증 실행 회차별 성공/실패 |
| LAMP 로그 | `lampLogAjax.do` | 게이트웨이 요청/응답 원문 |

이력에는 **언제(일시), 누가(처리자), 무엇을(단계 변화), 결과(성공/실패/사유)** 가
남습니다. 반려 사유와 오류 메시지도 이력에서 확인할 수 있어, 문제가 생겼을 때 가장
먼저 볼 곳입니다.

## LAMP 로그

LAMP는 게이트웨이 호출 로그 수집 체계입니다. 배포 상세 화면의 LAMP 로그 팝업에서
실제로 나간 요청 헤더·본문과 받은 응답을 그대로 볼 수 있습니다. 로그 파일 경로는
서버의 `/var/log/LAMP/` 이고, 서비스명과 채널 ID가 설정에 지정되어 있습니다.

## 자주 묻는 질문

**Q. 상태가 `DEPLOY1065` 에서 안 넘어갑니다.**
A. 운영 배포 실행을 아직 안 눌렀거나, 실행했지만 게이트웨이 응답이 오지 않은
상태입니다. LAMP 로그로 요청이 실제로 나갔는지 확인하세요.

**Q. `ROLLING_BACK` 이 뜨면 어떻게 되나요?**
A. 배포 중 실패해서 이전 정의로 되돌리는 중입니다. 롤백이 끝나면 게이트웨이에는
이전 상태가 남고, 신청 건은 실패로 표시됩니다. 원인을 고쳐 재배포해야 합니다.

**Q. 이력이 비어 있습니다.**
A. 아직 어떤 처리도 일어나지 않은 신규 신청 건입니다. 신청만 하고 승인 요청을 하지
않았다면 이력이 없을 수 있습니다.

**Q. 상태 코드가 화면마다 다르게 보입니다.**
A. 배포 단계 코드(`DEPLOY10xx`)와 게이트웨이 작업 상태(`DEPLOYING` 등)는 다른
체계입니다. 앞의 것은 결재 절차 단계, 뒤의 것은 실제 게이트웨이 연동 작업의 진행
상태입니다.
