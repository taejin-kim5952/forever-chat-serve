# 파일 업로드와 다운로드

게시판 첨부, API 문서, YAML 스펙, 엑셀 반입 등 파일을 다루는 자리가 여러 곳에
있습니다. 처리 방식은 공통 모듈 하나로 모여 있습니다.

## 화면·호출

| 기능 | URL |
|---|---|
| 파일 다운로드 | `/apidev/file/fileDownLoad.do` |
| 다중 파일 업로드 | `/apidev/api/main/mutiUploadFile.do` (POST) |
| YAML 파일 저장 | `/apidev/api/reg/saveYamlFileAjax.do` (POST) |
| YAML 다운로드 | `/apidev/api/reg/yamlDownload.do` |

파일 다운로드는 비로그인 허용 경로입니다. 다만 다운로드 대상이 비공개 자료면 서버가
권한을 다시 확인합니다.

## 업로드 제한

| 항목 | 값 |
|---|---|
| 파일 1개 최대 | 10MB |
| 요청 전체 최대 | 10MB |

여러 파일을 한 번에 올릴 때는 **합계**가 10MB를 넘지 않아야 합니다. 넘으면 업로드
자체가 거부됩니다.

## 저장 경로

파일 종류별로 저장 위치가 나뉩니다. 경로는 환경별 설정으로 관리됩니다.

| 종류 | 설정 키 |
|---|---|
| 이미지 | `imageServer.host` |
| YAML | `yamlServer.host`, `yaml.file.path` |
| 파일 타입 | `typeServer.host` |
| API 문서 | `apidocServer.host` |
| WSDL | `wsdlServer.host` |
| 업로드(요청) | `upload.path.request` |
| 업로드(마스터) | `upload.path.master` |
| apidoc 출력 | `upload.output.path` |

## 저장되는 파일 정보

업로드한 파일은 실제 파일과 별개로 DB에 정보가 기록됩니다.

| 항목 | 설명 |
|---|---|
| 첨부 번호 | 내부 식별자 |
| 저장 파일명 | 서버에 저장된 실제 이름(중복 방지용으로 변형됨) |
| 원본 파일명 | 사용자가 올린 이름. 다운로드 시 이 이름으로 내려갑니다 |
| 파일 타입 | 확장자·MIME |
| 파일 경로 | 저장 위치 |
| 파일 크기 | 바이트 |
| 다운로드 횟수 | 내려받은 횟수 |

저장 파일명을 바꾸는 이유는 같은 이름의 파일이 서로 덮어쓰지 않게 하기 위해서입니다.
사용자에게는 항상 원본 파일명으로 보입니다.

## 한글 파일명

다운로드 시 브라우저별로 한글 파일명이 깨지지 않도록 서버가 인코딩을 맞춰
내려보냅니다. 그래도 깨진다면 브라우저 설정이나 프록시의 영향일 수 있습니다.

## 보안 처리

- 업로드된 내용은 XSS 필터를 거칩니다.
- 실행 가능한 확장자는 업로드가 제한됩니다.
- 다운로드 경로에 상위 디렉터리 이동(`../`)이 섞이지 않도록 검사합니다.

## 자주 묻는 질문

**Q. 파일이 업로드되지 않습니다.**
A. 크기 제한(10MB)을 먼저 확인하세요. 여러 개를 올린다면 합계가 기준입니다.

**Q. 다운로드하면 파일명이 이상합니다.**
A. 서버 저장명이 아니라 원본명으로 내려가는 것이 정상입니다. 깨진 한글이 보이면
브라우저를 바꿔 시도해 보세요.

**Q. 올린 파일을 지우고 싶습니다.**
A. 첨부한 글에서 삭제하면 목록에서 빠집니다. 실제 파일 정리는 운영 작업입니다.

**Q. 큰 엑셀을 반입해야 합니다.**
A. 10MB를 넘으면 시트를 나눠 여러 번 올리거나, 개발지원으로 일괄 반입을 요청하세요.

**Q. 업로드는 됐는데 목록에 안 보입니다.**
A. 파일은 올라갔지만 글 저장이 실패한 경우입니다. 글을 다시 저장하면 첨부가
연결됩니다.
