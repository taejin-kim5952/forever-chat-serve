## 한눈에

```
data/
  qa_index.json               ★ 원본  사용자에게 나가는 답변 전부
  categories.json             ★ 원본  질문 주제 (대분류 5 / 카테고리 48)
  raw_docs/*.md               ★ 원본  RAG 문서
  profile.json                ★ 원본  납품처 브랜드·도메인 소개·언어 (없으면 기본값)
  ─────────────────────────────────────────────────────────────
  generated_qa.json             중간  검수 전 초안 (스튜디오 생성 결과)
  runtime_config.json           운영  관리자 화면에서 바꾼 임계값
  question_log.jsonl            운영  질문 이력
  question_embeddings.jsonl     운영  질문 벡터 (군집 분석이 재사용)
  analytics.json                운영  군집 분석 결과
  ─────────────────────────────────────────────────────────────
  eval_report.json              파생  마지막 품질 평가 결과 (진행 현황이 읽음)
  chroma/                       파생  벡터 저장소 — 지워도 재색인으로 복구
  logs/app.jsonl                파생  애플리케이션 로그
```

| 구분 | 뜻 | 배포 시 |
| --- | --- | --- |
| **원본** | 사람이 만든 것. 없으면 서비스가 안 됩니다 | **옮깁니다** |
| **중간** | 검수 대기 상태. 사용자에게 안 나갑니다 | 옮기지 않습니다 |
| **운영** | 운영 중에 쌓입니다 | **덮어쓰지 않습니다** |
| **파생** | 위에서 다시 만들 수 있습니다 | 옮기지 않습니다 |

> **폐쇄망 배포는 원본 복사로 끝납니다** — `qa_index.json` · `categories.json` ·
> `raw_docs/` · `profile.json`. DB를 세울 필요가 없습니다.

## `profile.json` — 납품처마다 달라지는 문자열

조직 이름과 도메인 설명이 화면 마크업과 생성 프롬프트에 박혀 있으면 설치할 때마다 소스를
고쳐야 합니다. 그 문자열만 이 파일 하나로 모았습니다 → [`app/core/profile.py`](../app/core/profile.py)

| 키 | 쓰이는 곳 | 기본값 |
| --- | --- | --- |
| `organization` | 로고 정사각형. **4자 넘으면 잘립니다** | `KT` |
| `service_name` | 화면 제목·브라우저 탭·`/docs` 제목 | `API Manager 도우미` |
| `service_desc` | 챗봇 헤더 한 줄 소개 | `API 등록 · 그룹 · 템플릿` |
| `domain_intro` | 생성 프롬프트 첫 문장 | `KT OpenAPI Portal 'API Manager' 사용 가이드` |
| `language` | 생성 결과 언어 판정 | `ko` |

**파일이 없으면 위 기본값이 나옵니다** — 기존 설치는 아무것도 하지 않아도 됩니다.
양식은 [`data/profile.example.json`](../data/profile.example.json) 에 있습니다.

`language` 가 가장 중요합니다. `ko` 만 실제 판정기가 있고(`app/studio/korean.py`), 그 외
언어는 **거르지 않고 통과**시킵니다. 한국어 판정을 그대로 들이대면 다른 언어 조직에서는
생성한 초안이 전부 버려지고 "완료, 0건"으로 끝납니다.

화면에 반영하는 방식은 `data-brand="{service_name}"` 속성이고, 서버(`app/main.py` 의
`_render()`)가 텍스트만 갈아 끼웁니다. 마크업은 그대로 남으므로 퍼블 산출물을 다시 받아도
속성만 다시 붙이면 됩니다.

`.gitignore` 로 저장소에서 빠지는 것: `data/chroma/` · `data/generated_qa.json` ·
`data/logs/` · `data/question_log.jsonl` · `data/question_embeddings.jsonl` ·
`data/analytics.json` · `data/runtime_config.json`

## `qa_index.json` — 가장 중요한 파일

사용자에게 나가는 답변이 전부 여기 있습니다.

```json
{
  "items": [
    {
      "qa_id": "qa_ab12cd34",
      "question": "API 등록은 어떻게 하나요?",
      "answer": "…마크다운…",
      "variants": ["API 등록하는 방법 알려줘", "API 등록 절차"],
      "category_id": "c_api_reg",
      "source_doc_ids": ["api-등록"],
      "status": "approved",
      "hit_count": 12,
      "created_at": "2026-08-15T09:00:00",
      "updated_at": "2026-08-15T10:30:00",
      "created_by": "ai",
      "model_used": "gemma4:latest",
      "note": ""
    }
  ]
}
```

| 필드 | 설명 |
| --- | --- |
| `question` | 대표 질문. 관리자 목록의 제목이자 변형 질문의 기준 |
| `answer` | 사용자에게 그대로 나가는 마크다운. 화면은 굵게/목록/코드/문단만 렌더합니다 |
| `variants` | **적중률은 사실상 이 목록이 결정합니다** |
| `status` | `pending` · `approved` · `hold` · `disabled`. **`approved` 만 인덱스에 올라갑니다** |
| `hit_count` | 실제로 몇 번 걸렸는지. 검수 우선순위의 근거 |
| `created_by` | `ai`=스튜디오 생성, `human`=사람이 직접 |
| `note` | 검수 메모. **보류한 이유를 안 남기면 다음 사람이 같은 판단을 반복합니다** |

벡터 인덱스에 올라가는 문장은 `question` + `variants` 입니다(중복·공백 제거).

**사람이 diff 로 볼 수 있게** JSON 파일로 둡니다. 누가 어떤 답변을 고쳤는지 git 으로 봅니다.

## `categories.json` — 질문 주제

```json
{
  "groups": [
    {
      "group_id": "g_api",
      "group_name": "API 관리",
      "categories": [
        {"category_id":"c_api_reg","name":"API 등록","enabled":true,
         "questions":["API 등록 절차","API 등록 항목 설명"]}
      ]
    }
  ],
  "quick_category_ids": ["c_api_reg","c_group","c_tmplt"]
}
```

| 항목 | 설명 |
| --- | --- |
| `enabled` | `false` 면 챗봇에 노출되지 않습니다 (관리자 화면에는 보입니다) |
| `questions` | 주제를 고르면 뜨는 **추천 질문** |
| `quick_category_ids` | 챗봇 첫 화면의 **자주 찾는 주제** 칩. **최대 6개**, 순서가 노출 순서 |

`quick_category_ids` 에 없는 카테고리 ID가 들어오면 서버가 422로 거부합니다.

초기 생성: `python scripts/seed_categories.py`

## `raw_docs/*.md` — RAG 문서

프론트매터 + 마크다운입니다.

```markdown
---
title: API 등록
category: API 관리 > API 등록
url: /api/spcreg/def/mvApiDefReg.do?apiSpcNo={그룹번호}
related: [spc-등록, 템플릿-관리]
updated: 2026-08-12
---

# API 등록

본문…

## 절

### 하위 절
```

| 프론트매터 | 쓰임 |
| --- | --- |
| `title` | 출처 배지·문서 카드에 표시 |
| `category` | 분류. QA 생성 시 `category_id` 매칭에 씁니다 |
| `url` | "문서로 이동" 링크 |
| `updated` | 관리자 문서 목록에 표시 |
| `related` | 사람이 읽을 때 참고용. `[[문서ID]]` 링크도 본문에 씁니다 |

**파일명(확장자 제외)이 `doc_id`** 입니다.

### 청킹 규칙

`##` 과 **`###` 까지** 잘라 청크를 만듭니다. 첫 헤딩 앞 도입부도 버리지 않습니다.

`###` 청크는 부모 제목을 잃기 쉬우므로 `section_path` 에 `부모 > 자식` 으로 남깁니다.
화면 카드의 섹션명이 "1)" 같은 조각으로 뜨는 것을 막기 위한 것입니다.

> **왜 `###` 까지 자르나** — 한 절에 항목이 여러 개면 청크가 3천 자에 달합니다. 그러면
> (1) 한 청크에 주제가 섞여 벡터가 뭉개지고 (2) 카드에 보여줄 발췌를 어디서 잘라야 할지
> 알 수 없습니다.

문서를 추가·수정하면 재색인이 필요합니다(관리자 화면에서 저장하면 자동).

## `generated_qa.json` — 검수 전 초안

스튜디오가 만든 결과입니다. **`qa_index.json` 과 일부러 파일을 나눴습니다** — "사람 손을 안
탄 것"과 "검수 대상"이 파일 단위로 구분돼야 실수로 배포되지 않습니다.

여기 있는 것은 **사용자에게 나가지 않습니다.** `apply` 하면 `qa_index.json` 에 `pending`
상태로 들어가고, 승인해야 서비스됩니다.

## `question_log.jsonl` — 질문 이력

한 줄에 한 건인 JSONL입니다.

```json
{"log_id":"lg_x","asked_at":"2026-08-15T10:00:00","question":"…","lang":"ko",
 "category_id":"c1","category_label":"API 등록","result_type":"answer",
 "matched_qa_id":"qa_x","matched_question":"…","similarity":0.974,
 "response_time_ms":712,"answer":"…","source_doc_titles":["API 등록"],
 "ticket_id":null,"user_id":null,"channel":"web"}
```

`channel` 이 `web` 이면 실사용, `auto` 면 내부 테스트입니다. **테스트가 실사용 통계를
흐리지 않게** 나눠 둔 값입니다.

**이 파일은 로그가 아니라 데이터입니다.** 관리자 화면(탭 ①)이 읽어가므로 `data/` 에 두고,
애플리케이션 로그(`logs/app.jsonl`)와 섞지 않습니다.

## `question_embeddings.jsonl` — 질문 벡터

답변할 때 이미 계산한 질문 임베딩을 base64 float32로 저장합니다.

**군집 분석이 이걸 재사용합니다.** 그래서 분석에 재임베딩이 없고, GPU 없는 운영에서도
돌아갑니다.

---

## `analytics.json` — 군집 분석 결과

비슷한 질문을 묶은 결과와, **사람이 지정한 상태·주제(`overrides`)** 가 함께 들어 있습니다.
overrides 는 따로 보관돼 다시 분석해도 남습니다.

군집 상태: `new` · `reviewed` · `generated` · `applied` · `excluded`

반영됩니다 → [06. 설정](06-설정.md)

## `chroma/` — 벡터 저장소

컬렉션 두 개가 들어 있습니다.

| 컬렉션 | 내용 |
| --- | --- |
| `qa_index` | 검수된 QA의 대표 질문 + 변형 질문 |
| `doc_chunks` | 문서 청크 |

**파생물입니다.** 지워도 재색인으로 복구됩니다.

```bash
curl -u admin:비밀번호 -X POST "http://localhost:18100/api/admin/qa/reindex?include_docs=true"
```

컬렉션 메타데이터에 **색인에 쓴 임베딩 모델**을 적어 둡니다. `.env` 의 모델과 다르면
`EmbedModelMismatch` 를 던집니다 — 차원이 다른 벡터를 섞으면 검색이 조용히 망가지기
때문입니다.

## 파일을 안전하게 쓰는 방법

`app/core/jsonstore.py` 가 **임시파일에 쓰고 rename** 합니다. 쓰다가 프로세스가 죽어도
반쪽짜리 JSON이 남지 않습니다.

새 저장 파일을 추가할 때는

1. `app/core/config.py` 에 경로 설정 추가
2. **`tests/conftest.py` 의 `overrides` 에도 추가** ← 빠뜨리면 테스트가 실제 `data/` 를
   덮어씁니다
3. `jsonstore` 를 통해 쓰기
