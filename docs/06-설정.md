# 06. 설정

`.env` 전 항목과, 재시작 없이 바뀌는 값이 무엇인지 정리합니다.

← [05. 데이터 파일](05-데이터-파일.md) · 다음 [07. 테스트](07-테스트.md)

---

## 설정이 두 겹인 이유

| | 기동 설정 | 런타임 설정 |
| --- | --- | --- |
| 어디에 | `.env` / 환경변수 | `data/runtime_config.json` |
| 코드 | `app/core/config.py` (`Settings`) | `app/core/runtime_config.py` |
| 누가 바꾸나 | 개발자·운영자 (파일/환경변수) | **관리자 화면 탭 ⑧** |
| 언제 반영 | **재시작해야** (`@lru_cache`) | **매 요청마다 파일을 다시 읽어 즉시** |

임계값처럼 운영 중에 조정하는 값은 재시작 없이 바뀌어야 합니다. 그래서 두 겹입니다.

같은 이름의 값이 양쪽에 있으면 **런타임 설정이 이깁니다** — 관리자가 화면에서 바꾼 것이
`.env` 기본값을 덮습니다.

---

## `.env` 전 항목

`.env.example` 을 복사해서 쓰고, `.env` 는 커밋하지 않습니다(`.gitignore`).

### 실행 모드

```
APP_MODE=serve
```

| 값 | 뜻 |
| --- | --- |
| `serve` | 운영. LLM 없이 임베딩 + 검색만. QA 생성/평가/문서편집이 403 |
| `studio` | 사내 작업 PC. 위 전부 가능 |

화면은 이 값을 `<body data-mode>` 로 받아 동작하지 않는 탭을 감춥니다.

### 관리자 인증

```
ADMIN_USERNAME=admin
ADMIN_PASSWORD=change-me
```

**운영 배포 전에 반드시 바꾸세요.** 기본값이면 기동 로그에 경고가 남습니다.

비밀번호를 코드나 파일에 두지 않습니다. 운영은 환경변수(또는 Secret)로만 주입합니다.

### 관리자 세션

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| `SESSION_COOKIE_NAME` | `admin_session` | 쿠키 이름 |
| `SESSION_TTL_MINUTES` | `480` | 세션 유효기간(분) |
| `SESSION_SECRET` | (빈 값) | 쿠키 서명 키 |

`SESSION_SECRET` 이 비어 있으면 **기동할 때마다 새 키를 만듭니다.** 서버를 재시작하면
로그인이 풀리지만, 키를 파일이나 코드에 남기지 않는 쪽이 안전합니다.

> **파드를 여러 개로 늘릴 때는 반드시 값을 주세요.** 안 주면 파드마다 서명 키가 달라,
> 한 파드에서 로그인하고 다른 파드로 요청이 가면 로그인이 풀립니다.

### Ollama

```
OLLAMA_HOST=http://localhost:11434
OLLAMA_EMBED_MODEL=bge-m3:latest
OLLAMA_LLM_MODEL=gemma4:latest
OLLAMA_THINK=false
OLLAMA_NUM_CTX=8192
OLLAMA_NUM_PREDICT=1024
```

| 설정 | 설명 |
| --- | --- |
| `OLLAMA_EMBED_MODEL` | **serve 모드에서도 필요합니다** — 질문을 벡터로 만들어야 검색이 됩니다 |
| `OLLAMA_LLM_MODEL` | studio 전용. serve 에서는 로드하지 않습니다 |
| `OLLAMA_THINK` | **`false` 로 두세요.** 추론(thinking) 모델은 사고 과정만 내보내고 본문을 비웁니다 — 답변이 통째로 사라집니다 |
| `OLLAMA_NUM_CTX` | 프롬프트가 이 창을 넘으면 초과분이 **조용히** 잘립니다. 발췌를 미리 자르는 기준이기도 합니다 |
| `OLLAMA_NUM_PREDICT` | 생성 최대 토큰. 답변이 늘 같은 지점에서 끊기면 올립니다 |

> **임베딩 모델을 바꾸면 반드시 재색인해야 합니다.** 차원이 달라집니다
> (bge-m3 1024 ↔ embeddinggemma 768). 자세히 → [10. 함정](10-함정.md)

### 매칭 임계값

```
QA_MATCH_THRESHOLD=0.90
RELATED_DOCS_FLOOR=0.55
RELATED_DOCS_COUNT=3
```

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| `QA_MATCH_THRESHOLD` | 0.90 | 이 값 이상이면 검수된 답변을 그대로 보여줍니다 |
| `RELATED_DOCS_FLOOR` | 0.55 | 답변에 못 미쳐도 이 값 이상인 문서가 있으면 문서만 보여줍니다 |
| `RELATED_DOCS_COUNT` | 3 | 문서 카드 최대 개수 |
| `QA_TOP_K` | 10 | QA 검색 시 상위 몇 건을 놓고 고를지 |
| `DOC_TOP_K` | 10 | 문서 검색 시 |

`QA_TOP_K` 를 넉넉히 두는 이유는 **같은 QA의 변형 질문이 여러 개 잡히기 때문**입니다.

> **`RELATED_DOCS_FLOOR` 는 반드시 `QA_MATCH_THRESHOLD` 보다 낮아야 합니다.** 서버가
> 강제합니다. 역전되면 `related_docs` 구간이 사라져 답을 못 찾은 질문이 전부 `unresolved`
> 로 떨어집니다.

**0.90 은 아직 근거가 없는 값입니다.** 품질 평가(탭 ⑦)로 숫자를 내서 정하는 것이 남아
있습니다 → [08. QA 생성과 검수](08-QA-생성과-검수.md#품질-평가)

### 벡터 저장소

```
CHROMA_PERSIST_DIR=./data/chroma
CHROMA_QA_COLLECTION=qa_index
CHROMA_DOC_COLLECTION=doc_chunks
```

### 파일 경로

| 설정 | 기본값 |
| --- | --- |
| `QA_INDEX_FILE` | `./data/qa_index.json` |
| `CATEGORIES_FILE` | `./data/categories.json` |
| `RUNTIME_CONFIG_FILE` | `./data/runtime_config.json` |
| `QUESTION_LOG_FILE` | `./data/question_log.jsonl` |
| `QUESTION_EMBEDDING_FILE` | `./data/question_embeddings.jsonl` |
| `ANALYTICS_FILE` | `./data/analytics.json` |
| `GENERATED_QA_FILE` | `./data/generated_qa.json` |
| `RAW_DOCS_DIR` | `./data/raw_docs` |

> **경로 설정을 새로 추가하면 `tests/conftest.py` 의 `overrides` 에도 넣으세요.**
> → [07. 테스트](07-테스트.md)

### 군집 분석

```
CLUSTER_SIMILARITY_THRESHOLD=0.85
```

이 값 이상으로 가까운 질문끼리 한 군집으로 묶습니다.

### 로깅

```
LOG_LEVEL=INFO
LOG_FILE=C:/chatapp/logs/app.jsonl
```

애플리케이션 로그는 JSON 한 줄에 한 건이고 5MB씩 5개까지 회전합니다. 상한이 없으면 지우는
사람이 없어 파일 하나가 수 GB가 됩니다.

**코드 기본값(`./data/logs/app.jsonl`)은 그대로 두세요** — 운영은 Linux라 절대경로를 박으면
배포가 깨집니다. 개발 PC에서만 저장소 밖 경로를 `.env` 로 지정합니다(저장소를 다시 받아도
로그가 남습니다).

## 런타임 설정 (관리자 화면 탭 ⑧)

`data/runtime_config.json` 에 저장되고 **매 요청마다 파일을 다시 읽습니다.**

| 항목 | 비고 |
| --- | --- |
| `qa_match_threshold` | |
| `related_docs_floor` | `qa_match_threshold` 보다 작아야 함 (서버 강제) |
| `related_docs_count` | |

API로도 바꿀 수 있습니다.

```bash
curl -u admin:비밀번호 -X PUT http://localhost:18100/api/admin/settings \
     -H "Content-Type: application/json" \
     -d '{"qa_match_threshold":0.88,"related_docs_floor":0.55,"related_docs_count":3}'

curl -u admin:비밀번호 -X POST http://localhost:18100/api/admin/settings/reset
```

범위를 벗어나거나 역전되면 **422** 입니다.

## 환경별로 무엇이 달라지나

| | 개발 PC | studio (사내 작업 PC) | 운영 (AKS) |
| --- | --- | --- | --- |
| `APP_MODE` | `serve` 또는 `studio` | `studio` | **`serve`** |
| LLM 모델 | 선택 | 필요 (9GB급) | **불필요** |
| 임베딩 모델 | 필요 | 필요 | 필요 |
| `ADMIN_PASSWORD` | 아무 값 | 실제 값 | **Secret 주입** |
| `SESSION_SECRET` | 비워도 됨 | 비워도 됨 | **반드시 지정** (파드 6개) |
| `LOG_FILE` | 저장소 밖 절대경로 | 상동 | 기본값 또는 볼륨 경로 |

## 로컬에서 자주 바꾸는 조합

**QA를 직접 생성해 보고 싶을 때**

```
APP_MODE=studio
OLLAMA_LLM_MODEL=gemma4:latest
```

**임계값을 낮춰 검색이 어디까지 걸리는지 보고 싶을 때**

관리자 화면 탭 ⑧에서 바꾸세요. `.env` 를 고치면 재시작해야 합니다.

**Ollama 가 다른 PC에 있을 때**

```
OLLAMA_HOST=http://192.168.0.10:11434
```
