## 격리 장치 두 개

`tests/conftest.py` 의 **autouse 픽스처** 두 개가 모든 테스트에 자동으로 걸립니다.
개별 테스트가 격리를 잊어도 실제 데이터에 닿지 않습니다.

### ① `isolated_data` — 모든 경로를 임시 디렉터리로

```python
overrides = {
    "chroma_persist_dir":       str(tmp_path / "chroma"),
    "qa_index_file":            str(tmp_path / "qa_index.json"),
    "categories_file":          str(tmp_path / "categories.json"),
    "runtime_config_file":      str(tmp_path / "runtime_config.json"),
    "question_log_file":        str(tmp_path / "question_log.jsonl"),
    "question_embedding_file":  str(tmp_path / "question_embeddings.jsonl"),
    "analytics_file":           str(tmp_path / "analytics.json"),
    "generated_qa_file":        str(tmp_path / "generated_qa.json"),
    "raw_docs_dir":             str(tmp_path / "raw_docs"),
    "log_file":                 str(tmp_path / "logs" / "app.jsonl"),
    "admin_username": "tester",
    "admin_password": "secret",
}
```

로그 핸들러도 다시 겁니다. `setup_logging()` 은 `app.main` 을 import 하는 순간(= 테스트 수집
시점) **실제 설정으로** 한 번 돌기 때문입니다. 그대로 두면 테스트 로그가 개발·운영 로그
파일에 섞입니다. **실제 데이터를 건드리지 않는다는 규칙은 `data/` 뿐 아니라 로그에도
적용됩니다.**

### ② `fake_embedder` — Ollama 를 부르지 않습니다

```python
class FakeEmbedder:
    DIM = 64
    def _vector(self, text):
        vector = [0.0] * self.DIM
        for char in text:
            vector[ord(char) % self.DIM] += 1.0
        norm = sum(v*v for v in vector) ** 0.5 or 1.0
        return [v / norm for v in vector]
```

글자 단위 해시 버킷을 셉니다. 실제 임베딩과 값은 다르지만 **"비슷한 문장이 더 가깝다"는
성질은 유지**되므로 임계값 분기를 검증할 수 있습니다.

테스트는 검색 **로직**을 검증하는 것이지 모델 성능을 재는 것이 아닙니다.

## ★ 새 경로 설정을 추가했다면

**`tests/conftest.py` 의 `overrides` 에 반드시 넣으세요.**

빠뜨리면 그 파일만 조용히 실제 `data/` 를 가리킵니다. 실제로 `generated_qa_file` 을 빠뜨려
**테스트가 생성 초안 파일을 덮어쓴 적**이 있습니다.

지금은 안전장치가 있습니다.

```python
leaked = sorted(
    name for name, value in settings.model_dump().items()
    if (name.endswith("_file") or name.endswith("_dir"))
       and not str(value).startswith(str(tmp_path))
)
assert not leaked, f"테스트 격리 누락 — 실제 경로를 가리키는 설정: {', '.join(leaked)}"
```

이름이 `_file` · `_dir` 로 끝나는 설정 중 하나라도 임시 폴더 밖을 가리키면 **테스트가 그
자리에서 멈춥니다.** 이 assert 가 터지면 격리를 빠뜨린 것입니다.

## 모듈 전역 상태 초기화

생성·평가 잡과 벡터 클라이언트는 **모듈 전역**이라, 초기화하지 않으면 앞 테스트의 상태가
다음 테스트로 샙니다. conftest 가 앞뒤로 초기화합니다.

```python
vector_store.reset_client()
retrieve.reset_retriever()
runner.reset_job()
evaluate.reset_job()
```

새로 전역 상태를 두는 모듈을 만들면 **`reset_*()` 함수를 만들고 conftest 에 추가하세요.**

## 테스트를 쓸 때

### 인증이 필요한 API

conftest 가 계정을 `tester` / `secret` 으로 고정합니다.

```python
def test_qa_list(client):
    res = client.get("/api/admin/qa", auth=("tester", "secret"))
    assert res.status_code == 200
```

### studio 전용 기능

모드를 바꿔야 합니다. `Settings` 를 다시 만들어 monkeypatch 하는 방식은
`test_studio_generate.py` 에 예시가 있습니다.

serve 모드에서 **403이 나는 것**도 테스트해야 합니다 — 게이팅이 깨지면 운영에 LLM이
들어옵니다.

### 임계값 분기

`FakeEmbedder` 특성상 **글자가 겹칠수록 유사도가 올라갑니다.** 그 성질을 이용해 문항을
만듭니다. `test_retrieve.py` 를 참고하세요.

## 테스트로 잡히지 않는 것

> **생성 프롬프트를 고쳤으면 실제 모델로 소량 실행해 눈으로 보세요.**
>
> ```bash
> python scripts/generate_qa.py --max 2
> ```
>
> 테스트의 LLM은 가짜라 **형식 이탈·문서 베끼기가 잡히지 않습니다.** 실제로 도입부에서
> 메타 질문("이 문서는 무엇을 설명하나요")이 나오고 문서 내부 표기(`[[문서ID]]`)가 답변에
> 섞여 나온 적이 있습니다.

임베딩 모델 성능, 답변 품질, 한국어 자연스러움도 테스트가 잡지 못합니다. 그건 품질 평가
기능(탭 ⑦)과 사람 검수의 몫입니다.
