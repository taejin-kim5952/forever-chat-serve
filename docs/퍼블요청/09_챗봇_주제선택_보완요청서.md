# API Manager 도우미 — 챗봇 주제 선택 보완 요청서

> **프로젝트**: `openapi-chat-serve`
> **대상 파일**: `chat.html` · `chat.css` · `chat.js` · `chat-mapping.md`
> **선행 요청서**: `01_사용자_챗봇화면_퍼블요청서.md` · `04_챗봇화면_보완요청서.md`
> **범위**: 인트로의 `전체 주제 보기` 동작 하나. **새 컴포넌트를 만드는 요청이 아닙니다.**

`04` 의 세 버튼(새 대화 · 답변 복사 · 맨 아래로) 잘 받아서 붙였습니다. `.is_new` 점 표시까지
그대로 동작합니다.

이번은 **실제 데이터로 화면을 켜 놓고 써 보다가 발견한 것 하나**입니다. 분량이 아주 적습니다.

## 1. 무슨 일이 일어나는가

인트로의 `전체 주제 보기` 를 눌렀는데 **아무 일도 안 일어난 것처럼 보입니다.**

실제로는 열립니다. 다만 **누른 곳에서 400px 넘게 떨어진 화면 맨 아래**, 입력창 바로 위에
열립니다. 사용자는 누른 자리를 보고 있으므로 그 패널을 못 봅니다.

```
┌──────────────────────────────────────────────┐
│  무엇이 궁금하신가요?                          │
│  주제를 먼저 고르시면 …                        │
│                                              │
│  자주 찾는 주제                                │
│  (API 등록 절차) (그룹 생성 절차) …            │
│  전체 주제 보기 ▾   ←─ ① 여기를 누르면        │
│                                              │
│              …빈 대화 영역…                    │
│                                              │
│  ┌────────────────────┐                      │
│  │ 주제 선택        ✕ │  ←─ ② 여기가 열립니다 │
│  │ 🔍 주제 검색        │      (화면 맨 아래)    │
│  │ ▸ API 등록     (12) │                      │
│  │ ▸ 그룹 관리    (9)  │                      │
│  └────────────────────┘                      │
│  ＃ 주제 선택 ▾                                │
│  [질문을 입력하세요            ] [전송]        │
└──────────────────────────────────────────────┘
```

원인은 마크업 위치입니다. 버튼은 인트로 안에 있고, 패널은 입력창 영역 안에 있습니다.

| | 파일·위치 |
| --- | --- |
| 누르는 버튼 `.chat_cat_more` | `chat.html` — `.chat_intro` 안 |
| 열리는 패널 `#chatCatPopover` | `chat.html` — `.chat_compose` 안 |
| 위치를 정하는 규칙 | `chat.css` — `.chat_cat_popover { position:absolute; bottom:100%; }` |

`.chat_compose` 가 `position:relative` 라 패널은 **항상 입력창 위**에 붙습니다.
아래 `＃ 주제 선택` 버튼에서 열 때는 바로 위에 붙어서 자연스럽습니다. **인트로에서 열 때만**
어긋납니다.

### 왜 그냥 두면 안 되는가 ★

이 챗봇은 **주제를 고르면 검색 정확도가 올라갑니다.** 인트로에 `주제를 먼저 고르시면 더
정확하게 찾아드립니다` 라고 적어 두고, 정작 그 안내 바로 아래 있는 버튼이 반응이 없어
보입니다. 첫 화면에서 제품이 고장 난 것처럼 보이는 자리라 우선순위를 높게 봤습니다.

## 2. 요청 — 인트로에서는 **그 자리에서** 펼쳐 주세요

두 가지 방법이 있습니다. **A안을 권합니다.**

### A안 (권장) — 인트로 안에서 아코디언으로 펼침

```
│  자주 찾는 주제                                │
│  (API 등록 절차) (그룹 생성 절차) …            │
│  전체 주제 보기 ▴          ← 누르면 캐럿이 뒤집히고 │
│  ┌──────────────────────────────────┐        │
│  │ 🔍 주제 검색                      │        │
│  │ ▸ API 등록                  (12) │        │
│  │ ▾ 그룹 관리                  (9) │        │
│  │     · 그룹 생성 절차              │        │
│  │     · 권한그룹 설정               │        │
│  │ ▸ 템플릿                     (8) │        │
│  └──────────────────────────────────┘        │
```

- 인트로는 **세로 공간이 넉넉합니다.** 대화가 없는 상태라 가릴 것도 없습니다
- 위치 계산이 필요 없어 **스크롤·창 크기 변경에 어긋나지 않습니다**
- 목록·검색·대분류 접기는 **지금 팝오버 안의 마크업을 그대로** 쓰시면 됩니다

### B안 — 팝오버 하나를 두고 위치만 계산

누른 버튼 기준으로 `top`/`left` 를 잡아 띄우는 방식입니다. 마크업이 한 벌로 유지되는 장점이
있지만, 대화 목록이 스크롤되는 영역 안에서 열리는 것이라 **스크롤·리사이즈마다 위치를 다시
잡아야** 합니다. 이 화면에서는 A안이 단순합니다.

### 어느 안이든 지켜 주실 것

- **아래 `＃ 주제 선택` 팝오버는 지금 그대로 두세요.** 대화가 시작되면 인트로가 사라지고
  그때부터는 아래 버튼만 씁니다. 잘 동작합니다
- 인트로에서 주제를 고르면 **아래 트리거도 함께 선택 상태**가 되어야 합니다
  (`.chat_cat_trigger_wrap.is_active` + 주제 이름 표시). 지금 `자주 찾는 주제` 칩이 그렇게
  동작하고 있으니 같은 흐름이면 됩니다
- 주제를 고른 뒤에는 펼침을 닫고 **입력창에 포커스**를 주세요
- 인트로가 사라질 때(첫 질문 전송) 펼침도 함께 닫혀야 합니다

## 3. 함께 봐주실 것 — 처음 열면 **대분류 5줄만** 보입니다

패널을 열면 하위 주제가 전부 접혀 있어 이런 화면이 나옵니다.

```
🔍 주제 검색
▸ API 등록        (12)
▸ 그룹 관리        (9)
▸ 템플릿           (8)
▸ 오류 대응        (11)
▸ 운영 관리        (8)
```

**주제가 48개인데 5줄만 보입니다.** 한 번 더 눌러야 나온다는 것을 모르면 "목록이 비었다"로
읽힙니다. 아래 트리거로 열 때도 같습니다.

- 처음 열 때 **첫 대분류는 펼쳐 주세요.** 하위 항목이 어떻게 생겼는지 한눈에 보이면
  나머지도 눌러 볼 수 있습니다
- 대분류 줄에 **손가락 커서**(`cursor:pointer`)와 hover 배경이 지금보다 분명하면 좋겠습니다.
  지금은 눌러도 되는 줄로 안 보입니다
- 검색어를 넣으면 전부 펼쳐지는 지금 동작은 좋습니다. 그대로 두세요

## 4. 개발이 붙잡고 있는 이름 (바꾸지 말아주세요)

서버 연동과 테스트가 이 이름들을 씁니다. 마크업이 옮겨 다녀도 **이름은 유지**해 주세요.

| 요소 | ID / 클래스 | 개발이 쓰는 방식 |
| --- | --- | --- |
| 주제 한 건 | `.chat_cat_item[data-category-id]` | 클릭 → 그 값을 질문과 함께 서버로 보냅니다 |
| 대분류 | `.chat_cat_group[data-group-id]` · `.chat_cat_group_head` | 접기/펼치기 |
| 검색 입력 | `#chatCatSearch` | 목록 필터 |
| 목록 컨테이너 | `#chatCatList` | 서버 응답으로 **매번 다시 그립니다** |
| 아래 팝오버 | `#chatCatPopover` | 그대로 유지 |
| 아래 트리거 | `#chatCatTrigger` · `.chat_cat_trigger_wrap` | 선택 상태 표시 |
| 인트로 칩 | `.chat_cat_quick_chip[data-category-id]` | 그대로 유지 |
| 인트로 | `#chatIntro` · `.chat_intro_sub` | 첫 질문 시 숨김 |

### ★ 주제 목록은 **서버에서 옵니다**

`chat.js` 가 `/api/categories` 응답으로 목록을 그립니다. 대분류 5개 · 주제 48개는 **지금
납품처의 값일 뿐**이고, 다른 설치처에서는 개수도 이름도 다릅니다.

- 개수를 마크업에 박지 말아주세요 (`(12)` 같은 숫자도 스크립트가 채웁니다)
- **하나도 없는 경우**도 있습니다. 그때는 `전체 주제 보기` 와 `자주 찾는 주제` 소제목이
  숨겨집니다(이미 그렇게 동작합니다). 그 상태에서도 인트로가 어색하지 않아야 합니다
- 이름이 길 수도 있습니다. 한 줄 넘칠 때 줄임표 처리를 유지해 주세요

## 5. 접근성

- `전체 주제 보기` 에 `aria-expanded` 를 붙여 주세요(지금 없습니다). 펼침 상태를 읽어야 합니다
- 펼친 목록은 `role="listbox"` / 항목은 `role="option"` — 지금 팝오버 규칙 그대로입니다
- 키보드: 검색칸에서 `↓` 로 목록 진입, `↑↓` 이동, `Enter` 선택, `Esc` 닫고 버튼으로 복귀.
  **아래 팝오버에 이미 다 들어가 있습니다.** 인트로 쪽도 같게 해주세요
- 캐럿(`▾`/`▴`)만으로 상태를 알리지 말고 `aria-expanded` 를 함께 주세요
