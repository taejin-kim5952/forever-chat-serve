## 2. 문제 — 기준 파일이 1차 프로젝트 것입니다 ★

산출물과 함께 온 `uploads/챗봇_디자인퍼블_요청서.md` 가 **요청서 01**, 그것도 이전 저장소
(`openapi-chat`) 기준이었습니다.

> `openapi-chat`이라는 신규 서비스로 … **로컬 LLM/RAG 파이프라인**은 이미 동작하는 상태이고

그 문서가 전달되면서, 11번을 **가장 오래된 화면 위에** 얹으신 것으로 보입니다. 그 사이 요청서
03~10 이 반영돼 화면이 많이 달라졌습니다.

### 관리자 화면 구조가 다릅니다

| | 이번 산출물 | 현재 제품 |
| --- | --- | --- |
| 구성 | 상단 **탭 5개** | 좌측 **사이드바 10항목** (요청서 05) |
| 항목 | 시스템 프롬프트 · RAG 문서 · 질문 카테고리 · 질문 분석 · 임계값 | 진행 현황 · RAG 문서 · 질문 카테고리 · QA 생성 · **검수** · QA 인덱스 · 질문 이력 · 질문 분석 · 품질 평가 · 설정 |

`시스템 프롬프트` 탭은 지금 제품에 **없습니다.** 운영 서버에 AI 모델을 올리지 않기로 해서
그 화면이 존재할 수 없습니다. 반대로 `검수` 는 이 제품의 중심 화면인데 빠져 있습니다 —
**11번 진입 버튼이 놓일 자리가 바로 거기입니다.**

### 03~10 작업이 통째로 빠져 있습니다

산출물에서 다음 표식을 찾지 못했습니다.

| 요청서 | 표식 | 산출물 |
| --- | --- | --- |
| 03 로그인 모달 | `#authModal` | 없음 |
| 04 새 대화 · 맨 아래로 | `#chatReset` · `#chatToBottom` | 없음 |
| 05 사이드바 10항목 | `.admin_nav_item` | 없음 |
| 06 작업 현황판 | `#flowJobHistory` | 없음 |
| 09 인트로 주제 펼침 | `#chatIntroCats` | 없음 |
| 10 답변 피드백 | `.chat_fb_down` | 없음 |

파일 크기로도 드러납니다.

```
admin.js   현재 149,350 → 산출물 101,912   (-47KB)
chat.js    현재  42,522 → 산출물  27,263   (-15KB)
```

이대로 반영하면 **그동안 만든 화면이 전부 사라집니다.**

## 3. 재작업 요청 — 이것만 해주시면 됩니다

**현재 파일을 기준으로 11번 모달만 다시 얹어 주세요.**

### 3-1. 기준 파일

이 요청서와 같은 폴더의 **`11-1_기준파일/`** 에 넣어 두었습니다. **이 파일들이 현재 제품의
정본**입니다.

```
11-1_기준파일/
  admin.html   71.6KB      chat.html   14.7KB
  admin.css    58.7KB      chat.css    26.9KB
  admin.js    145.8KB      chat.js     41.5KB
```

> 이 파일들에는 **서버 연동 코드가 들어가 있습니다.** 화면 로직(렌더·이벤트)은 산출물 그대로
> 두었으니 그 부분만 보시면 됩니다. 서버를 부르는 줄은 건드리지 말아 주세요.

### 3-2. 넣을 것

1. **진입 버튼** `#qaImportBtn` — `검수` 화면(`#panel_review`) 머리 오른쪽
2. **모달** `#qaImportModal` — 이번에 만드신 것 그대로
3. **CSS** — `.admin_import_*` 관련 블록

이번 `chat.*` 는 반영하지 않습니다. 11번은 관리자 화면 작업이라 챗봇 쪽은 손댈 것이 없습니다.

### 3-3. 넣지 말 것

- 탭 5개 구조 · `시스템 프롬프트` 탭
- 기존 화면의 다른 부분 수정 — **11번 외에는 아무것도 바꾸지 말아 주세요**
- `data-dev-only` 안의 CDN·상대경로 폴백은 남겨 두셔도 됩니다(개발이 이식할 때 걷어냅니다)

## 4. ★ 다음부터 — 산출물이 이전 모습을 되돌려 옵니다

이번만의 일이 아니라 **매번 겪고 있습니다.** 산출물은 현재 파일을 모르는 상태에서 만들어지니
자연스러운 일이고, 다음 두 가지로 줄일 수 있습니다.

**작업 시작 전에 기준 파일을 확인해 주세요.** 요청서에 적힌
`app/static/admin.*` · `chat.*` 가 정본입니다. 함께 받은 참고 자료가 그것과 다르면
작업 전에 한 번 물어봐 주시면 좋겠습니다.

**요청 범위 밖은 손대지 말아 주세요.** 지난 산출물에서 실제로 되돌아온 것들입니다.

| 되돌아온 것 | 결과 |
| --- | --- |
| 자동 스크롤 판정을 말풍선 붙인 **뒤**로 되돌림 | 긴 답변에서 하단 추종이 깨집니다 |
| 관련 문서 카드의 `chunk_id` 배선 소실 | 문서 첫머리로 열려 "왜 이 문서지?"가 됩니다 |
| `중지 요청됨` 안내 문구 한글 깨짐 | `중지 요잭됨 … 멈충니다` |

개발이 diff 로 걸러내고 있지만, 매번 같은 자리를 다시 확인하게 됩니다.
