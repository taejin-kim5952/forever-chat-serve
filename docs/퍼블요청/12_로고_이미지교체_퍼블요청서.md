## 3. 지금 상태 — 로고가 나오는 자리는 3곳입니다

전부 글자를 넣은 `span` 이고, CSS 로 색만 칠한 뱃지입니다.

| # | 파일 | 줄 | 요소 | 위치 |
| --- | --- | --- | --- | --- |
| 1 | `chat.html` | 20 | `.chat_logo` | 챗봇 헤더 왼쪽 |
| 2 | `admin.html` | 18 | `.qr_logo` | 관리자 상단바 왼쪽 |
| 3 | `admin.html` | 1402 | `.qr_logo` | 관리자 로그인 모달(`#authModal`) 머리 |

```html
<span class="chat_logo" data-brand="{organization}">KT</span>
<span class="qr_logo"   data-brand="{organization}">KT</span>
```

```css
/* chat.css:80 */                      /* admin.css:73, 175 */
.chat_logo{                            .qr_logo{
  height:24px;padding:0 8px;             height:22px;padding:0 7px;
  border-radius:4px;                     border-radius:4px;
  background:var(--qr-accent);           background:var(--qr-accent);
  color:#fff;font-size:12px;             color:#fff;font-size:11px;
  font-weight:800;                       font-weight:800;
}                                      }
                                       .qr_logo{max-width:52px;}
```

`--qr-accent` 는 `#c93137` 이고, **헤더 배경은 `#fff` 흰색**입니다. 즉 지금은 *흰 헤더 위에 붉은
뱃지, 그 안에 흰 글자* 입니다.

## 4. ★ 먼저 알려 드릴 것 — 받으신 로고가 흰색 단색입니다

`logo.png` 의 픽셀을 세어 봤습니다.

| 색 | 비율 |
| --- | --- |
| 투명 | 69.9% |
| 흰색 `#FEFEFE` · `#FFFFFF` | 27.1% |
| 빨강 `#E40815` | 0.1% |

**글자 부분이 전부 흰색입니다.** 어두운 배경 전용(역상) 로고입니다. 그래서:

- 붉은 뱃지(`#c93137`) **위에 얹으면 잘 보입니다**
- 뱃지 배경을 걷어내고 흰 헤더에 바로 올리면 **로고가 보이지 않습니다**

### 그래서 이렇게 해 주세요

**뱃지의 붉은 배경을 그대로 두고, 그 안의 글자만 이미지로 바꿔 주세요.** 배경을 없애지 말아
주세요. 이러면 지금 보이는 모습과 가장 가깝고, 로고도 제대로 보입니다.

> 흰 배경에 로고를 그대로 놓는 모습을 원하시면 **컬러(정상) 버전 로고 파일이 따로 필요합니다.**
> 저희가 가진 건 흰색 역상 버전뿐입니다. 그 방향이 낫다고 보시면 작업 전에 말씀해 주세요 —
> 컬러 파일을 구해서 다시 보내 드리겠습니다.

## 5. 받으실 파일

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `logo.png` | 172 × 42 (32bit ARGB, 투명 배경) | **이번에 쓸 것** |
| `ft_logo.png` | 163 × 42 (32bit ARGB, 투명 배경) | 푸터용. 이번 작업에는 쓰지 않습니다 |

KT OpenAPI 포털(`openapi-mng`)에서 실제로 쓰는 로고 원본입니다.

### 비율 때문에 헤더 폭이 늘어납니다

로고가 **약 4.1 : 1** 로 가로가 깁니다. 지금 뱃지 높이에 맞추면 이렇게 됩니다.

| 자리 | 높이 | 이미지 폭 | 지금 뱃지 폭 |
| --- | --- | --- | --- |
| 챗봇 헤더 | 24px | 약 98px | 약 36px |
| 관리자 상단바 | 22px | 약 90px | 최대 52px (`max-width`) |

브랜드 영역이 **50~60px 가량 넓어집니다.** 옆에 붙는 서비스 이름(`.chat_title`)과 간격
(`.chat_header_brand{gap:10px}`)이 어색해지지 않게 같이 봐 주세요. `admin.css:175` 의
`max-width:52px` 는 글자 기준으로 잡아 둔 값이라 **이미지에 맞게 풀거나 키워 주셔야 합니다.**

## 6. 넣을 것

### 6-1. 마크업 — 3곳 모두 같은 방식으로

`span` 은 그대로 두고 **안에 `img` 를 넣어 주세요.** 뱃지 배경·모서리 둥글기가 `span` 에 걸려
있어서 그렇습니다.

```html
<span class="chat_logo">
  <img class="chat_logo_img" src="./images/logo.png" alt="KT">
</span>
```

- 이미지 경로는 **퍼블 확인용으로 편한 경로**로 두시면 됩니다. 실제 배포 경로는 개발이 맞춥니다
- `alt` 는 `KT` 로 넣어 주세요

### 6-2. `data-brand` 속성은 빼 주세요 ★

지금 3곳 모두 `data-brand="{organization}"` 가 붙어 있고, 이 속성이 있으면 **스크립트가 로고
자리에 글자를 다시 써 넣어 이미지를 지웁니다** (`admin.js:452~467`).

```
<span class="chat_logo" data-brand="{organization}">   →   <span class="chat_logo">
```

**`admin.js` 의 치환 블록 자체는 건드리지 말아 주세요.** 속성만 빼시면 됩니다. 조직 이름을
`alt` 로 넣는 배선은 개발이 따로 합니다.

### 6-3. CSS

```css
.chat_logo_img{ height:100%; width:auto; display:block; }
```

정도면 됩니다. `span` 의 `padding` 은 로고가 답답해 보이지 않을 만큼 조정해 주셔도 됩니다.
`font-size` · `font-weight` · `letter-spacing` 처럼 **글자용 속성은 지워 주세요.**
