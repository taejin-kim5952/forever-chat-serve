> **프로젝트**: `openapi-chat-serve`
> **원 요청서**: `13_사용자화면_재설계_퍼블요청서.md`

## 1. 디자인과 설계는 그대로 쓰겠습니다

먼저 이것부터 말씀드립니다. **요청서 13 의 내용은 빠짐없이 들어왔습니다.**

- **앞표지 커버 카드**, 한 줄에 하나, 세로 스크롤 — 요청한 모양 그대로입니다
- **세 가지 선택**(AI 답변 · 모델 · 추론 과정)과, ①이 꺼지면 ②③이 비활성이 되는 **묶임 규칙**
- **추론 블록 → 답변 → 참고 자료** 순서와, 답변이 시작되면 추론이 자동으로 접히는 동작
- **검수 전 / 검수 완료 배지가 동시에 나오지 않는다**는 규칙까지 지켜 주셨습니다
- 첫 화면의 질문 카드와 규모 한 줄

`chat-mapping.md` 도 저희가 기대한 것보다 자세합니다. 특히 **SSE 이벤트별 화면 동작**과
**상태 규칙**을 적어 주신 부분은 그대로 구현 기준으로 쓰겠습니다.

금지 사항도 전부 지켜 주셨습니다 — 외부 CDN 0건, `data-dev-only` 0건, 조직 이름 하드코딩
0건, 유지 약속한 이름(`#chatInput` `#chatSend` `.chat_msg` `.chat_md` `[data-doc-open]`)
전부 그대로였습니다.

**디자인·클래스 이름·동작 규칙은 하나도 바꾸지 말아 주세요.** 아래 2번만 바꾸면 됩니다.

## 2. 문제 — 저희 화면이 이 산출물을 실행하지 못합니다 ★

받은 `Chat.dc.html` 은 **디자인 캔버스 산출물**이라, 평범한 HTML 이 아니라 컴포넌트와
템플릿 문법으로 되어 있습니다.

```html
<x-import component-from-global-scope="KTDesignSystem_8b180c.Switch"
          id="chatAiMode" checked="{{ aiOn }}" onChange="{{ setAi }}"></x-import>

<sc-if value="{{ multiModel }}"> … </sc-if>
```

| 들어 있는 것 | 개수 |
| --- | --- |
| `<x-import …>` 디자인 시스템 컴포넌트 (Switch · Select · Button · Tag · Popup) | 10 |
| `<sc-if>` · `<sc-for>` 조건·반복 태그 | 34 |
| `{{ }}` 상태 바인딩 | 144 |
| 외부 의존 | `_ds/kt-design-system-…/` (CSS 11개 + `_ds_bundle.js`) · `support.js` 69KB |

### 왜 그냥 못 쓰는가

저희 사용자 화면은 **jQuery + 순수 HTML/CSS** 한 벌입니다(`chat.html` · `chat.css` ·
`chat.js`). 지금까지의 이식 방식은 **"산출물의 마크업·클래스를 그대로 두고 서버 배선만
얹는다"** 였는데, 이 산출물은 마크업 자체가 다른 런타임을 전제로 합니다.

디자인 시스템을 통째로 반입하는 방법도 생각해 봤지만 접었습니다.

- 이 제품은 **폐쇄망에 도커 이미지 한 파일로 반입**합니다. 런타임이 하나 더 늘면 반입물과
  검증 범위가 함께 늘어납니다
- `support.js` 와 `_ds_bundle.js` 는 **저희가 고칠 수 없는 코드**입니다. 화면에서 문제가
  나면 원인을 짚을 수가 없습니다
- 저희 화면 테스트가 **id·class 와 서버 호출을 직접 검사**합니다. 템플릿 바인딩으로 돌면
  그 검사가 통째로 무력해집니다

## 3. 요청 — 같은 화면을 평범한 HTML 로

### 3-1. 컴포넌트를 표준 태그로 바꿔 주세요

| 지금 | 바꿔 주실 모양 |
| --- | --- |
| `KTDesignSystem.Switch` | `<label class="…"><input type="checkbox" id="chatAiMode"><span class="…"></span>AI 답변</label>` |
| `KTDesignSystem.Select` | `<select id="chatModel" class="…"><option>…</option></select>` |
| `KTDesignSystem.Button` | `<button type="button" class="…">…</button>` |
| `KTDesignSystem.Tag` | `<span class="…">…</span>` |
| `KTDesignSystem.Popup` | `<div class="… is_open">` + CSS 로 여닫기 |

**생김새는 지금 시안과 똑같이** 만들어 주시면 됩니다. 디자인 시스템의 색·간격·모서리 값을
CSS 로 옮겨 적어 주시면 저희 화면에 그대로 얹습니다.

### 3-2. 템플릿 문법 대신 마크업 + 클래스로

- `<sc-if value="{{ x }}">` → **요소를 그냥 두고** `hidden` 속성이나 `.is_hidden` 클래스로
  감춥니다. 저희가 상태에 따라 붙였다 뗍니다
- `<sc-for>` → **반복되는 한 건을 `<template>` 으로** 주세요. 저희가 복제해 채웁니다
  (지금 `chat.html` 이 쓰는 방식입니다 — `tpl_answer` · `tpl_related_item` 등)
- `{{ 값 }}` → **`data-bind="이름"` 속성**으로 자리만 표시해 주세요. 값은 저희가 넣습니다

```html
<!-- 이렇게 주시면 됩니다 -->
<template id="tpl_cover">
  <button type="button" class="chat_cover" data-doc-open>
    <span class="chat_cover_title" data-bind="title"></span>
    <span class="chat_cover_meta"><span data-bind="chunk_count"></span>개 절 ·
      <span data-bind="category"></span></span>
  </button>
</template>
```

### 3-3. 인라인 `style` 은 CSS 파일로

지금 `style="…"` 이 103곳에 있습니다. **`chat.css` 한 파일로** 모아 주세요. 인라인으로
있으면 저희가 상태별 모양(선택됨·비활성·스트리밍 중)을 덧붙일 수가 없습니다.

### 3-4. 더미 동작은 남겨 주세요

시안에서 **SSE 더미로 글자가 흘러나오는 것**을 보여 주신 부분은 그대로 두시면 좋겠습니다.
바닐라 JS 로 옮겨 주시고, 저희가 그 자리에 실제 서버 연결을 끼우겠습니다.

## 4. 내보내실 파일

```
chat.html        ← 마크업 + <template>. 커스텀 엘리먼트·템플릿 문법 없이
chat.css         ← 모든 스타일 (인라인 style 없음)
chat.js          ← 더미 데이터·더미 SSE 로 동작하는 바닐라 JS
chat-mapping.md  ← 지금 주신 것 그대로 (바뀐 이름만 반영)
```

jQuery 는 저희 쪽에 이미 있으니 쓰셔도 되고, 바닐라로 주셔도 됩니다. **다른 라이브러리는
넣지 말아 주세요.**

## 5. 내보내시기 전에 확인

저희가 받으면 아래를 그대로 검사합니다. 미리 돌려 보시면 왕복이 줄어듭니다.

- [ ] `<x-import` · `<sc-if` · `<sc-for` · `{{` 가 **하나도 없습니까?**
- [ ] `_ds/` · `support.js` 없이 **`chat.html` 만 열어도** 화면이 뜹니까?
- [ ] `style="` 속성이 없습니까? (스타일이 전부 `chat.css` 에 있습니까)
- [ ] 외부 주소(`http://` · `https://`)를 부르는 곳이 없습니까?
- [ ] `data-dev-only` 가 없습니까?
- [ ] 조직 이름(`포에버소프트` · `KT`)을 마크업에 직접 쓰지 않았습니까?
- [ ] 유지 약속한 이름이 그대로입니까? — `#chatInput` `#chatSend` `.chat_msg` `.chat_md`
      `[data-doc-open]` `[data-brand]` `[data-brand-logo]`
- [ ] 반복되는 것이 전부 `<template>` 으로 나와 있습니까?
- [ ] 폰트가 **로컬 파일**입니까? (Pretendard 를 쓰신다면 파일을 함께 주세요)
