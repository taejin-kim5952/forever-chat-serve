# 신규 디자인(foreversoft-drive) ↔ 지식LAB 기능 매핑

> **받은 것**: `퍼블/신규디자인퍼블/foreversoft-drive/` (2026-10-06) — `drive.html` ·
> `folder-new.html` · `admin-users.html` + CSS 4 · JS 4 · 로고 2
> **성격**: 이름은 '드라이브'지만 **지금 만들고 있는 지식LAB의 사용자 화면**이다. 교체본이
> 아니라 **정본**으로 삼는다 — 우리 기능을 이 디자인에 맞춰 넣는다. 반대로 하지 않는다.
>
> **상태(2026-10-06)**: 퍼블이 바빠서 **이식과 보완을 우리가 직접 했다.** 아래 매핑대로
> 들어가 있다. 무엇을 어떻게 했는지는 8·9번에 적었다.

## 1. 먼저 확정된 세 가지

| 질문 | 결정 |
| --- | --- |
| 목록의 '파일'이 무엇인가 | **원본(ppt·pdf·doc·xls)과 그것을 정리한 `.md` 를 한 쌍으로 올린다.** 검색은 `.md` 로 하고, 답변의 참고 자료에서 **원본을 내려받는다** |
| '폴더'가 무엇인가 | **프로젝트**(`packs/<id>/`) — API Link · API Manager · MCP |
| 검수된 답변·피드백·접수번호가 어디로 가나 | **`AI 검색` 한 줄이 입구**. 첫 답은 패널에 나오고, 이어 물으면 **대화로 펼쳐진다** |

세 번째는 정하는 중에 한 번 뒤집혔다(2026-10-06). '패널에서 한 번 묻고 끝'으로 정했다가
**대화형 유지**로 되돌렸다 — 되묻지 못하면 사용자가 질문을 처음부터 다시 쓰게 되고, 그것이
이 제품에서 가장 잦은 동작이다. 그래서 지금 이식해 둔 `app/static/chat.*` 은 **버리지
않는다.** 그 말풍선·스트리밍이 곧 대화 영역이다(3번).

## 2. 자료 한 건의 새 구조 — 원본과 `.md` 가 짝을 이룬다 ★

지금은 `raw_docs/<doc_id>.md` 하나가 문서 한 건이다. 여기에 **원본 파일 자리**를 붙인다.

```
packs/mcp-manager/raw_docs/
  mcp-개념-개요.md              ← 색인된다. AI 가 읽는 것은 이것뿐
  files/mcp-개념-개요.pptx       ← 보관·다운로드용. 색인하지 않는다
```

**짝은 파일 이름으로 맺는다.** `폴더 업로드`가 이미 "파일 이름이 곧 문서 ID"
(`app/ingestion/doc_upload.py`)로 돌고 있어서, 같은 이름의 `.pptx` 와 `.md` 를 함께 끌어다
놓으면 서버가 알아서 한 건으로 묶는다. 짝을 짓는 화면을 따로 만들지 않아도 된다는 것이
이 규칙을 고른 이유다.

| 올린 것 | 목록에서 | 검색 | 다운로드 |
| --- | --- | --- | --- |
| `.md` + 원본 | 원본 아이콘(PPT·PDF…) · 원본 크기 · `절 N개` | **된다** | **원본** |
| `.md` 만 | `MD` 아이콘 | **된다** | `.md` 원문 |
| 원본만 | 원본 아이콘 + **`색인 안 됨`** 배지 | 안 된다 | 원본 |

마지막 줄이 중요하다. 원본만 올리면 **답변에 쓰이지 않는다** — 이것을 배지로 눈에 보이게
해야 한다. 안 보이게 두면 "올렸는데 AI가 모른다"가 되고, 그때 원인을 짚을 수가 없다.
텍스트 추출기(hwp·ppt 파서)는 넣지 않는다. 폐쇄망 반입물이 커지고, 추출 품질이 나쁘면
**답변 품질이 조용히 무너진다** — 사람이 정리한 `.md` 를 받는 쪽이 이 제품의 전제에 맞다.

### 늘어난 것 (들어감)

- `app/ingestion/doc_files.py` — 보관·찾기·지우기·용량. 경로 설정을 새로 만들지 않고
  `raw_docs/files/` 로 파생시켰다(설정이 늘면 `tests/conftest.py` 격리 목록에 넣는 것을
  잊은 날 테스트가 실제 `data/` 를 건드린다)
- `GET /api/drive/{doc_id}/file` — 원본 내려주기. 원본이 없으면 `.md` 원문을 준다
- 용량 집계는 `raw_docs/files/` 합계. **한도(1TB)는 두지 않고** `N GB 사용` 만 보여 준다
- 업로드가 **같은 입구에서** 둘을 받는다(`POST /api/admin/docs/upload`). 사람은 파일을
  한 번에 집으므로 종류별로 나눠 보내게 하지 않았다. 원본 상한은 50MB

## 3. `drive.html` — 요소별로 무엇이 되는가

### 좌측 사이드바

| 디자인 | 지식LAB | 지금 |
| --- | --- | --- |
| 로고 | 그대로. 값은 `data/brand/logo.svg` | 있음 |
| `홈` | **`AI 질문`** 으로 바꾼다 — 대화 화면으로 바로 들어가는 길 | 있음 (`chat.*`) |
| `드라이브` | 자료 목록 (메인) | 있음 |
| `최근 항목` | 후순위 | — |
| `휴지통` | 후순위 | — |
| `관리자 설정` | `/admin` 10탭으로 | 있음 |
| `저장 공간 1TB 중 620GB` | `N GB 사용` · 막대는 뺀다(한도가 없으므로) | 새로 |
| `용량 문의` 버튼 | 후순위 → 뺀다 | — |
| `로그아웃` · `홍길동` 아바타 | 후순위 → **관리자로 로그인했을 때만** 보인다 | 세션 쿠키만 있음 |

`홍길동` 자리가 문제다. 지금 제품에 사용자 계정이 없다. 사용자 화면은 **익명**으로 쓰고,
관리자가 로그인하면 그 자리에 `관리자` 가 뜨는 모양으로 간다. 사람 이름이 필요한 자리는
후순위(5번)로 미룬다.

### 폴더 = 프로젝트

| 디자인 | 지식LAB |
| --- | --- |
| 폴더 카드(팀 이름) | **프로젝트 카드** — `packs/<id>/pack.json` 의 이름 |
| `파일 17개` · `490 MB` | 문서 수 · 원본 합계 용량 |
| 카드를 누르면 그 폴더 파일만 | 프로젝트 선택 → **그 프로젝트 자료만**, 질문도 그 프로젝트로 한정 |
| 한 번 더 누르면 전체 | 전체 — **프로젝트를 가로질러 검색**한다 (6-3) |
| `+ 새 폴더` | `+ 새 프로젝트` → `folder-new.html` |

프로젝트 선택이 **질문 범위까지 정한다**는 점이 디자인에 없던 의미다. `ProjectMiddleware`
가 이미 `?project=` 를 읽으니 화면은 모든 요청에 그것만 실어 보내면 된다.

### AI 검색 + 대화 ★

디자인의 `AI 검색` 한 줄은 **대화의 입구**다. 여기서 물으면 `.ai-answer` 패널이 열려 첫 답이
그 자리에 나오고, 이어 물으면 **대화 영역으로 펼쳐져** 자료 목록 위를 덮는다. 돌아가는 길은
패널의 `✕` 와 좌측 `드라이브` 다.

왜 두 단계인가. 자료를 찾으러 온 사람의 첫 질문은 대개 한 번에 끝난다 — 그 한 번 때문에
화면을 옮기면 보고 있던 자료 목록을 잃는다. 반대로 되묻기 시작하면 열 줄짜리 패널로는 좁다.
그래서 **첫 답까지는 패널, 그 다음부터는 대화 영역**으로 간다.

`app/static/chat.*` 의 말풍선·스트리밍·피드백은 그대로 살아남는다. 빠지는 것은 **왼쪽 자료
서재** 하나다 — 드라이브 화면의 폴더 카드와 파일 목록이 같은 일을 하므로 두 번 둘 이유가 없다.

| 디자인 | 들어갈 것 | 서버 |
| --- | --- | --- |
| `AI 검색` 한 줄 | 첫 질문. 대화가 시작되면 **입력칸이 대화 영역 하단으로 내려가 고정된다** | `GET /api/chat/stream` (SSE) |
| — | **`AI 답변` 스위치 · 모델 선택 · 추론 과정** 세 가지. ①이 꺼지면 ②③ 비활성 | `GET /api/models` |
| `AI 요약` 머리 | **배지 두 종류** — `✓ 담당자 검수 답변` / `AI 정리`. **동시에 뜨지 않는다** | `done.mode` |
| `.ans-loading` 점 세 개 | 기다리는 표시 + **경과 초** | — |
| — | **추론 블록** — 답변이 시작되면 접힌다 | `thinking` 이벤트 |
| `.ans-body` | 답변 본문. 글자가 차오른다 | `answer` 이벤트 |
| `.ans-refs` 문서 버튼 | 참고 자료 — **원본 다운로드 버튼을 각 카드에 붙인다** | `sources` 이벤트 |
| — | **피드백 👍/👎** (검수 답변에만. 👎는 사유 3개를 말풍선 안에서 펼침) | `POST /api/feedback` |
| — | **담당자 문의 + 접수번호** (답을 못 찾았을 때) | `POST /api/support` |
| — | **이어 묻기 · `새 대화` · 답변 복사** | — |
| `.ans-note` AI 주의문 | 그대로. 단 **`AI 정리` 일 때만** 보인다 | — |
| `✕` 닫기 | 대화를 접고 자료 목록으로 돌아간다 | — |

검수 답변에는 주의문을 띄우지 않는다 — 사람이 승인한 문장이라 "다를 수 있다"가 틀린 말이
되고, 검수의 의미가 흐려진다.

대화 중에도 **프로젝트 범위는 유지된다.** 폴더를 고른 상태에서 물었으면 이어지는 질문도
그 프로젝트 안에서 찾는다. 중간에 범위가 바뀌면 같은 질문에 다른 답이 나오는 이유를
사용자가 알 수 없다.

### 필터 · 목록 · 업로드

| 디자인 | 지식LAB |
| --- | --- |
| 필터 `문서 종류` (PDF·PPT·DOC·XLS·HWP·ZIP·IMG) | **원본 확장자**. 원본을 보관하므로 그대로 쓸 수 있다 |
| 필터 `폴더` | 프로젝트 |
| `128개의 파일이 있습니다` | 실제 문서 수 |
| 보기(10/20/50/전체) · 정렬(등록일·이름·크기) | 그대로 |
| 목록 한 줄: 이름·폴더·올린 사람·크기·등록일 | 이름·프로젝트·**`절 N개`**·크기·등록일. 올린 사람은 후순위 |
| `최근 7일` 태그 | 그대로 |
| `읽기 전용` 태그 | 후순위(권한) → 자리를 **`색인 안 됨`** · **`QA N건`** 으로 바꿔 쓴다 |
| `⤓` 다운로드 | 원본(없으면 `.md`) |
| 끌어다 놓기 · 내 PC에서 선택 | **원본 + `.md` 를 함께** 받는다. 지금 폴더 업로드(`doc_upload.py`)를 그대로 쓴다 |
| 토스트 | 그대로 |

업로드는 **몇 건씩 나눠 보내는 지금 방식을 유지한다** — 한 요청에 다 보내면 진행 상황을
보여줄 수 없고, 타임아웃 뒤에 무엇이 들어갔는지 알 수 없다(CLAUDE.md).

## 4. `folder-new.html` — 새 프로젝트 만들기

| 디자인 | 지식LAB |
| --- | --- |
| `폴더 이름` | 프로젝트 이름 (`pack.json` · `profile.json` 의 `service_name`) |
| — | **프로젝트 ID** (영소문자·숫자·`-`) ← 폴더 이름이 되므로 반드시 필요 |
| `위치`(상위 폴더) | **뺀다** — 프로젝트는 한 단계다 |
| `설명` | 도메인 소개 (`profile.json`). **프롬프트에 들어간다**는 안내를 붙인다 |
| — | **언어** ← 없으면 다른 언어 조직에서 초안이 전부 버려진다 |
| `접근 권한` 카드 전체 | **후순위 — 카드째 감춘다** |
| `상위 폴더 권한 상속` | 후순위 |
| `읽기/편집/전체` 범례 | 후순위 |

권한 카드는 마크업을 지우지 않고 **감춰 둔다**. 나중에 되살릴 때 퍼블을 다시 부르지 않아도
되고, 디자인이 이미 그 모양을 정해 뒀기 때문이다.

## 5. `admin-users.html` — 지금은 쓰지 않는다

사용자 계정·권한은 **처음 기획에 없던 것**이라 후순위다. 다만 이 화면의 **틀**은 버리지
않는다 — `요약 카드 + 검색 툴바 + 테이블 + 빈 상태` 구성이 우리 관리자 화면의
`QA 인덱스` · `검수` · `질문 이력` 과 같은 모양이다. **관리자 10탭을 이 틀로 다시
그릴 때 기준으로 쓴다.**

## 6. 서버 쪽으로 새로 해야 하는 일

### 6-1. 원본 파일 보관 (2번)

`raw_docs/files/` · `GET /api/docs/{doc_id}/file` · 용량 집계 · `indexed` 플래그.

### 6-2. 목록 API

지금 `/api/library` 는 **주제(카테고리)별 책장**을 준다. 드라이브는 **파일 한 줄짜리 목록**이
필요하다 — 정렬·필터·페이지가 붙는다. 서가 응답을 비틀어 쓰지 않고 `GET /api/docs` 를
새로 만든다. 화면이 다르면 엔드포인트도 새로 만드는 것이 이 저장소의 규칙이다(CLAUDE.md).

카테고리 48개는 **목록에서는 쓰이지 않는다.** QA 의 주제 분류로 남아 검수·분석에서만 쓴다.

### 6-3. 프로젝트를 가로지르는 검색 ★

폴더를 고르지 않은 '전체' 상태가 **기본값**이다. 지금 `retrieve.py` 는 한 프로젝트
컨텍스트 안에서만 돈다. 전체일 때는 **질문 임베딩을 한 번만 계산해** 프로젝트마다 검색을
돌리고 유사도로 합쳐 정렬한다. 프로젝트가 세 개면 Chroma 질의가 세 번인데 각 수십 ms 라
체감되지 않는다 — 비싼 것은 임베딩이고 그것은 한 번이다.

### 6-4. 답변 패널에 맞춘 SSE

`sources` 이벤트에 **원본 정보**(`ext` · `bytes` · `downloadable`)를 더한다. 나머지
계약(`thinking` · `answer` · `sources` · `done`)은 그대로 쓴다.

## 7. 후순위로 미루는 것 (처음 기획에 없던 것)

| 미루는 것 | 왜 지금 안 하는가 |
| --- | --- |
| **사용자 계정** (이름·메일·비밀번호 메일) | 인증 체계를 통째로 바꾸는 일이다. 지금은 관리자 비밀번호 하나로 돈다 |
| **권한** (그룹 × 읽기/편집/전체, 상속) | 권한이 생기면 "승인된 QA는 누구에게나 같은 답"이 "보는 사람마다 다른 답"이 된다. 검색 단계에 필터가 들어가고 검수 기준도 흔들린다 |
| **올린 사람 · 등록자 추적** | 계정이 있어야 의미가 생긴다 |
| **휴지통 · 최근 항목 · 홈** | 자료가 쌓인 뒤에 필요해진다 |
| **저장 공간 한도 · 용량 문의** | 폐쇄망 단일 서버라 한도를 걸 상대가 없다 |
| **hwp·ppt 텍스트 추출** | 사람이 정리한 `.md` 를 받는 쪽이 품질이 높다. 추출 품질이 나쁘면 답변이 조용히 나빠진다 |

**마크업은 지우지 않고 감춘다.** 되살릴 때 디자인을 다시 받지 않기 위해서다.

## 8. 퍼블 대신 우리가 한 것

퍼블이 바빠서 **이식과 보완을 직접 했다**(2026-10-06). 디자인·클래스 이름·동작 규칙은
바꾸지 않았고, 없던 것만 같은 토큰(`--brand`·`--line`·`--ink` …)으로 더했다.

### 산출물에서 고친 것

| 고친 것 | 왜 |
| --- | --- |
| Google Fonts → 로컬 Pretendard | 운영은 폐쇄망이다. `common.css` 에서 **폰트 두 군데뿐** 바꿨다 |
| 상대경로 → `/static/...` | 화면을 `/` 에서 내려주므로 그대로 두면 404 가 되고 화면이 아예 안 뜬다 |
| 멀티페이지 → 한 셸 | `drive.html`(`/`) · `folder-new.html`(`/projects/new`, studio 전용). `admin-users.html` 은 쓰지 않는다 |
| 사용자 아바타 → 관리자 링크 | 사용자 계정이 후순위다. 사람 이름이 들어갈 자리를 비워 두지 않고 `관리자` 입구로 썼다 |
| 샘플 데이터 제거 | `const folders = [...]` · `const files = [...]` 를 서버 응답으로 바꿨다 |

### 더한 것

- **대화** — 말풍선 · 스트리밍 커서 · 경과 초 · 추론 블록(답이 시작되면 접힘) ·
  배지 두 종류(`✓ 담당자 검수 답변` / `AI 정리`, **동시에 뜨지 않는다**) · `새 대화` · 답변 복사
- **세 가지 선택** — `AI 답변` 스위치 · 모델 · 추론 과정. ①이 꺼지면 ②③은 덮개(`.blocker`)가
  클릭을 받아 **왜 못 쓰는지 알려 준다.** `disabled` 만 두면 눌러도 아무 일이 없어서 사용자는
  화면이 멈춘 줄 안다
- **피드백 👍/👎** — 검수된 답변에만. 👎는 사유 셋을 말풍선 안에서 펼친다(모달은 무거워서
  그냥 닫고 나간다). 사유 값은 서버가 정한 `mismatch`·`wrong`·`thin`
- **담당자 문의 + 접수번호** — 번호는 **서버가 준 값만** 쓴다. 버튼은 한 번 누르면 비활성
- **참고 자료 카드에 내려받기** — 근거는 `.md`, 내려받는 것은 원본. 같은 문서의 절이 여럿
  걸리면 **문서 단위로 접는다**(같은 카드가 두 번 나오면 고장처럼 보인다)
- **`색인 안 됨` · `QA N건` 배지** — 산출물의 `읽기 전용` 자리를 썼다
- **올리는 중 진행 막대** — 20건·20MB 로 나눠 보내고 건마다 결과를 보여 준다
- **자료 원문 모달** — 검수 전 AI 답변은 원문 확인이 전제라 반드시 열려야 한다
- **추천 질문** — `AI 질문` 을 누르면 패널에 뜬다. 서재를 뺀 자리를 메운다
  (`/api/drive` 의 `projects[].questions`)

### 디자인을 그대로 둔 곳

폴더 카드 · 좌우 스와이프 · 필터 패널 · 보기·정렬 드롭다운 · 파일 목록 · 드롭존 · 토스트 ·
사이드바 일러스트. 렌더 함수 이름도 산출물 그대로(`renderFolders`·`renderFiles`·
`renderChips`·`renderPanel`) 두어 **다음 산출물과 diff 를 뜰 수 있게** 했다.

### 관리자 10탭은 손대지 않았다

내부 화면이라 급하지 않다. `admin-users.html` 의 틀(요약 카드 + 검색 툴바 + 테이블 +
빈 상태)이 우리 `QA 인덱스`·`검수`·`질문 이력` 과 같은 모양이므로, 나중에 다시 그릴 때
기준으로 쓴다.

## 9. 들어간 순서와 남은 일

```
① 원본 파일 보관            app/ingestion/doc_files.py · GET /api/drive/{id}/file     ✔
② 자료 목록 API             app/api/drive.py (프로젝트 · 자료 · 용량 · 추천 질문)      ✔
③ 프로젝트 교차 검색        app/pipeline/scope.py                                    ✔
④ 사용자 화면 이식          drive.html · drive.css · drive.js · common.css            ✔
⑤ 대화 · 피드백 · 접수번호  drive.js                                                 ✔
⑥ 새 프로젝트 화면          folder-new.html · folder-new.js (studio 전용)             ✔
⑦ 관리자 10탭 재이식                                                                  미정
```

### 실제 데이터로 확인한 것 (2026-10-06)

```
프로젝트 3개 · 자료 28건 · 보관 144KB
'전체' 로 물은 질문 → api-manager 의 검수 답변 0.933 (고치기 전에는 unresolved)
MCP 질문        → mcp-manager 의 문서 카드 0.649
AI 답변(qwen3.5:4b) → 8.9초 · 출처 1건 · 프로젝트 mcp-manager
원본+본문 쌍 올리기 → 한 건(PPT 아이콘 · 2절 색인) · 40KB 원본 내려받기 성공
피드백 → var/api-manager/question_feedback.jsonl 에 기록 · 접수번호 TCK-...
테스트 395개 통과
```

### 고치면서 드러난 것

- **미들웨어가 모든 요청에 기본 프로젝트를 채우고 있었다.** 그래서 '전체' 로 물은 질문이
  빈 프로젝트에서만 찾다 전부 `unresolved` 로 떨어졌다. 오류가 아니라 "자료가 있는데
  모른다" 로만 드러나는 종류다. 요청이 **지목한 것**과 **기본값으로 채운 것**을 구분해
  고쳤다(`config.project_was_requested()`)
- **검수 미리보기가 표를 못 그리고 있었다.** 사용자 화면에만 표 렌더가 있어서, 검수자는
  멀쩡해 보이는 것을 승인하고 사용자는 깨진 표를 봤다. `admin.js` 에 맞춰 넣고 검사를 박았다
- **피드백·문의가 어느 팩에 쌓이는지 어긋날 수 있었다.** 서버가 `done` 이벤트에 어느
  프로젝트가 답했는지 실어 보내고, 화면이 그것을 뒤이은 요청에 붙인다

### 남은 일

- 관리자 10탭을 이 디자인 톤으로 다시 그리기(급하지 않음)
- 사용자 계정·권한(7번) — 지금 전제를 건드리므로 결정이 먼저다
- **지금 실제로 필요한 것은 코드가 아니라 QA 를 쌓는 일이다.** `mcp-manager` 는 문서 23건에
  승인된 QA 가 **0건**이라 질문하면 문서 카드만 나간다
