# API 찾기 - 카테고리 탐색과 AI 가이드챗

API Link 는 카테고리 탐색과 AI 가이드챗 두 가지 방법으로 필요한 KT API 를 찾도록 돕습니다.

## 카테고리로 API 를 탐색하는 방법

질문: API 는 어디서 찾나요 / 카테고리 탐색이 뭔가요 / API 목록은 어떻게 구성되나요 / API Explorer 가 뭔가요

API Link 의 **API Explorer** 는 포털에 등록된 KT API 를 분류별로 보여 주는 화면입니다. 분류를 따라 내려가면 그 아래 그룹과 API 가 나오고, 분류마다 들어 있는 API 수가 함께 표시되어 원하는 API 에 빠르게 접근할 수 있습니다.

API 이름이나 코드를 알고 있으면 검색어로 목록을 바로 좁힐 수 있습니다. API 를 고르면 그 API 의 규격 상세로 이어집니다.

## 규격 상세에서 확인할 수 있는 것

질문: API 규격은 어떻게 확인하나요 / 필수 파라미터는 어디서 보나요 / Request Response 확인 / 민감 파라미터 표시

API 를 고르면 **규격 상세**가 한 화면에 표시됩니다. 여러 문서를 오가지 않고 연동에 필요한 정보를 한 번에 확인하는 것이 목적입니다.

- 요청(Request) 파라미터와 **필수 여부**
- 응답(Response) 파라미터

민감 파라미터가 포함된 API 는 구독할 때 관리자 승인을 받아야 합니다. 일반 API 는 자동 승인됩니다.

## AI 가이드챗은 무엇인가

질문: AI 가이드챗이 뭔가요 / 말로 API 를 찾을 수 있나요 / 자연어로 API 검색 / AI 가이드챗은 어디서 쓰나요

**AI 가이드챗**은 자연어 질문 한 줄로 API 규격서에서 관련 API 와 원문 근거를 찾아 주는 기능입니다. API 이름을 몰라도 하고 싶은 일을 문장으로 물으면 됩니다.

예를 들어 "휴대폰 번호로 성인 인증하는 API를 찾아줘" 라고 물으면, 검색 대상 규격서(소개서 작성 시점 1,729건) 가운데 관련 API 를 골라 보여 줍니다. AI 가이드챗은 API Explorer 화면에서 엽니다.

## AI 가이드챗이 답을 찾는 방식

질문: AI 가이드챗은 어떻게 동작하나요 / 하이브리드 검색이 뭔가요 / 답변의 근거는 어디서 나오나요 / AI 가 답을 지어내나요

AI 가이드챗은 네 단계로 답을 만듭니다.

1. **질문 입력** - 사용자가 자연어로 질문합니다.
2. **하이브리드 검색** - 단어가 일치하는 것을 찾는 키워드 검색과, 뜻이 비슷한 것을 찾는 의미 검색을 함께 써서 질문의 의도를 파악합니다.
3. **규격서 매칭** - 검색 대상 API 규격서에서 관련 API 를 고릅니다.
4. **답변과 원문 근거** - 관련 API 목록과 함께, 답변의 근거가 된 규격서 원문과 API Explorer 바로가기를 보여 줍니다.

AI 가이드챗은 규격서에 적힌 내용을 그대로 보여 주는 것을 원칙으로 하며, 규격서에 없는 값은 '규격서에 없음' 으로 표시합니다. 정확한 값은 규격서 원문에서 확인합니다.
