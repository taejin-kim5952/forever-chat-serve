# API 생애주기와 운영 배포 승인

API 는 등록한 뒤 네 단계를 거쳐 운영에 올라갑니다. 이 문서는 그 단계와, 운영 배포가 승인되는
과정을 다룹니다.

## API 생애주기 네 단계

질문: 전체 절차가 어떻게 되나요 / 등록부터 운영까지 순서 / 몇 단계인가요 / API Life Cycle

등록부터 운영 배포까지 네 단계로 진행합니다.

1. **STEP 0 등록** — API 를 등록합니다.
2. **STEP 1 TB 배포** — TB 배포를 요청합니다.
3. **STEP 2 테스트** — 테스트를 실행하고 검증합니다.
4. **STEP 3 운영 배포** — 운영 배포를 요청하고 승인을 받습니다.

## 운영 배포 단계 상세

질문: 운영 배포 상태가 어떻게 바뀌나요 / 배포 대기가 뭔가요 / 요청하면 어떻게 되나요

운영 배포는 네 가지 상태를 차례로 지납니다.

`운영 배포 요청` → `운영 승인 대기` → `배포 대기` → `운영 배포 완료`

## 반려되었을 때와 요청을 취소할 때

질문: 반려되면 어떻게 하나요 / 요청을 취소할 수 있나요 / 승인 대기 중에 되돌리려면

- **반려된 경우** — 사유를 확인한 뒤 다시 요청합니다.
- **승인 대기 중인 경우** — `배포 요청 취소` 로 요청 상태로 되돌립니다.
- **승인이 취소된 경우** — 상태가 `운영 배포 요청` 으로 돌아갑니다.

## 승인자가 보는 화면

질문: 승인자는 어디서 승인하나요 / 승인 화면이 뭐가 있나요 / 반려 사유는 어떻게 전달되나요

승인자는 **요청 목록 · 요청 상세 · 대기 목록 · 대기 상세 · 이력** 순으로 처리합니다.
반려할 때는 사유를 입력하고, 그 사유가 등록자에게 전달됩니다.

## 권한 신청 흐름

질문: 권한은 어떻게 신청하나요 / 권한 신청 절차 / MY 권한에서 하는 일

권한 신청은 `신청` → `승인` 또는 `반려` 로 진행되고, 사용 기간이 지나면 `기간 만료` 가 됩니다.
연장 신청은 `승인` 과 `기간 만료` 상태에서만 할 수 있습니다.
