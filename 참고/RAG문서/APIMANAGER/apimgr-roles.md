# 사용자 역할과 권한

API Manager 를 쓰는 사람은 등록자와 승인자로 나뉩니다. 이 문서는 누가 무엇을 할 수 있는지와,
권한을 어떻게 신청하고 연장하는지를 다룹니다.

## 등록자와 승인자

질문: 등록자와 승인자 차이 / 역할이 어떻게 나뉘나요 / 누가 승인하나요 / 내가 쓸 수 있는 화면

| 역할 | 하는 일 | 쓰는 화면 |
| --- | --- | --- |
| 등록자 | API 그룹·API 를 등록하고 TB 배포 → 테스트 → 운영 배포를 요청합니다 | API 그룹 현황 · MY PAGE |
| 승인자 | 운영 배포 요청을 검토해 승인·반려하고, 승인한 건을 운영에 배포합니다 | 운영 배포 관리 |

로그인, 내 API·내 권한 확인, 권한 신청·연장은 **두 역할 모두** 쓰는 공통 기능이며 MY PAGE 에
있습니다.

## 로그인 방식

질문: 어떻게 로그인하나요 / 회원가입이 필요한가요 / Entra ID 로그인 / 계정은 어떻게 받나요

**Entra ID 로그인 전용**입니다. KT 와 KT DS 직원에게는 기본 권한이 자동으로 부여되며,
**회원가입이 없습니다.**

## 서비스별 권한 그룹

질문: 권한 그룹이 뭔가요 / 접근 범위는 어떻게 정해지나요 / 다른 서비스 API 도 보이나요

접근 범위는 **권한 그룹 단위**로 나뉩니다. 서비스별로 권한 그룹이 있고, 그 그룹이 조회·등록할
수 있는 범위를 정합니다.

## 권한 상태 네 가지

질문: 권한 상태가 뭐가 있나요 / 신청하면 어떻게 되나요 / 반려되면 / 기간이 끝나면

권한에는 사용 기간이 있고 상태는 네 가지입니다.

`신청` → `승인` · `반려` · `기간 만료`

## 권한 연장 신청

질문: 권한을 연장하려면 / 연장 신청은 언제 할 수 있나요 / 기간이 끝났는데 다시 쓰려면

**연장 신청은 `승인` 과 `기간 만료` 상태에서만 할 수 있습니다.** 신청 중이거나 반려된 권한은
연장할 수 없습니다. 신청과 연장은 MY PAGE 의 `MY 권한` 에서 합니다.
