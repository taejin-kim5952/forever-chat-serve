## API 등록 기능

질문: API 등록할 때 뭘 하나요 / 표준 템플릿이 뭔가요 / API ID 는 어떻게 만들어지나요 / 규격서 형식

API 등록(F-API)은 네 가지를 합니다.

- **표준 템플릿 적용**
- **API ID 중복 검사와 발급**
- **파라미터 트리 설계**
- **OpenAPI 규격서 생성** — YAML 과 JSON

## 배포 기능

질문: 배포할 때 뭘 하나요 / 롤백이 되나요 / 전문은 누가 만드나요

배포(F-DPL)는 **전문 생성 → 배포 요청 → 배포·롤백** 으로 이루어집니다. 전문은 서버가
만들고 화면은 조회·수정만 합니다.

## 테스트 자동 검증 네 항목

질문: 테스트에서 뭘 확인하나요 / 자동 검증 항목 / 성공 기준이 뭔가요 / 테스트 통과 조건

테스트(F-TST)는 네 항목을 자동으로 검증합니다.

1. **상태 코드 200**
2. **성공 기준**(`returnCode`)
3. **필수 출력 항목 존재**
4. **타입 규격 일치**

## 승인과 MY PAGE 기능

질문: 승인을 한꺼번에 할 수 있나요 / 다건 처리 / 승인 취소가 되나요 / 대기 집계가 뭔가요

승인(F-APV)은 **승인·반려를 다건으로 처리**하고 **대기 집계**와 **승인 취소**를 지원합니다.
MY PAGE(F-MY)는 권한 신청과 연장을 맡습니다.
