# API 그룹 현황 화면

API 그룹 현황은 권한이 있는 서비스의 API 그룹과 진행 상태를 한눈에 보는 메뉴입니다.
그룹 등록 · 그룹 상세 · 그룹별 API 목록 · API 상세 화면이 여기에 속합니다.

## 그룹 현황 보기

질문: API 그룹 현황이 뭔가요 / 그룹 목록이 어디 있나요 / 서비스가 트리에 안 보여요 / 확인 필요 탭이 뭔가요 / 그룹 검색은 어떻게 하나요

좌측 메뉴에서 'API 그룹 현황' 을 선택합니다. 로그인 직후와 상단 로고를 선택했을 때도 이 화면이 열립니다.
좌측에는 권한이 있는 서비스와 그룹이 트리로, 본문에는 그룹 목록이 표시됩니다. 권한이 있는 서비스만 트리에 나오므로, 서비스가 보이지 않으면 'MY PAGE > MY 권한' 에서 먼저 권한을 신청합니다.

- 트리에서 서비스를 선택하면 그 서비스의 그룹만 목록에 표시되고, 그룹을 선택하면 그룹별 API 목록으로 이동합니다. '그룹 검색' 에 글자를 입력하면 트리가 그 글자가 들어간 그룹만으로 줄어듭니다.
- '서비스 전체' · '확인 필요' · '진행중' · '완료' 탭으로 상태별로 추립니다. '확인 필요' 는 반려된 API 가 있는 그룹, '완료' 는 모든 API 가 운영 배포된 그룹입니다.
- 'SEARCH' 에 그룹명 · API 명 · API ID · Path 를 입력하면 그 값이 들어간 그룹이 검색됩니다.
- 그룹 카드의 색 막대는 등록 · TB 배포 · 테스트 · 운영 배포 · 반려 건수입니다. '그룹 상세보기' 버튼은 그룹 상세로, '신규 API 등록' 버튼은 그 그룹의 API 등록 화면으로 이동합니다.

## 그룹 등록

질문: 그룹은 어떻게 만드나요 / 신규 그룹 등록 / 호스트와 기본경로는 뭔가요 / 그룹 이름 글자수 / 권한그룹이 자동으로 들어가요

그룹 현황 오른쪽 위 '신규 그룹 등록' 버튼을 선택합니다. 화면은 '기본 정보' 와 '호스트 · 기본경로' 두 묶음이며 * 표시는 필수 항목입니다.

- 서비스를 선택하면 권한그룹이 자동으로 지정됩니다. 그룹 이름은 최대 50자, 설명은 최대 500자입니다. 그룹 이름은 규격서와 목록에 표시되는 이름입니다.
- 호스트와 기본경로는 그룹 안 모든 API 주소 앞에 붙는 값입니다. 기본값이 채워져 있으므로 별도로 협의된 값이 없으면 그대로 둡니다.
- 입력을 마치면 화면 아래 '저장' 버튼을 선택합니다. 저장되면 그룹 상세로 이동합니다.

그룹의 호스트 · 기본경로를 바꾸면 그룹 안 모든 API 주소가 함께 바뀝니다.

## 그룹 상세

질문: 그룹 상세에서 뭘 볼 수 있나요 / 테스트 BASEURL이 뭔가요 / 그룹 수정은 어디서 하나요 / 그룹 삭제 버튼이 안 보여요

그룹 카드의 '그룹 상세보기' 버튼을 선택하면 그룹의 기본 정보와 호스트 · 기본경로가 표시됩니다. '테스트 BASEURL' 은 TB 배포 후 테스트 단계에서 호출하는 주소입니다.
화면 아래 'API 목록' 버튼은 이 그룹의 API 목록으로, '수정' 버튼은 그룹 수정 화면으로 이동합니다. '그룹 삭제' 버튼은 설정에 등록된 관리자에게만 표시됩니다.

## 그룹별 API 목록과 다음 할 일

질문: API 목록은 어디서 보나요 / 다음 할 일이 뭔가요 / 진행 상태 점 네 개 / API 검색 / 반려된 API는 어떻게 하나요

좌측 트리에서 그룹을 선택하거나 그룹 상세의 'API 목록' 버튼을 선택합니다. 위쪽 '진행 단계' 에는 이 그룹의 API 가 단계별로 몇 건인지, 아래 목록에는 API 마다 진행 상태가 표시됩니다.
Method · 진행 단계를 고르고 검색어를 입력한 뒤 '검색' 버튼을 선택합니다. 검색 구분을 'API' 로 두면 API 명에서, 'Path' 로 두면 API 주소에서 찾습니다.

목록 오른쪽 '다음 할 일' 에는 그 API 가 지금 할 수 있는 작업 버튼이 표시됩니다. 등록 완료면 'TB배포', TB 배포 완료면 '테스트 실행', 테스트 완료면 '운영 배포 요청' 입니다. 반려된 API 는 '반려 사유 보기' 또는 '다시 요청' 이 표시됩니다. 버튼을 선택하면 해당 작업 화면으로 이동합니다.

## API 상세

질문: API 상세에서 뭘 볼 수 있나요 / JOB 칸이 뭔가요 / 버전 올리기는 언제 되나요 / API 수정은 어디서 하나요

목록에서 API 명을 선택하면 API 상세가 열립니다. 좌측에는 같은 그룹의 API 가 버전별로 표시되어 다른 API 로 바로 이동할 수 있습니다.
'진행 단계' 에는 지금 단계가 표시되고, 그 아래 JOB 칸에 단계 안의 세부 작업과 날짜 · 작업자가 표시됩니다. JOB 칸 오른쪽 버튼이 다음 작업입니다.
아래로 내려가면 API 이름 · API ID · Method · Path 와 파라미터, 규격서가 순서대로 표시됩니다. 화면 아래 버튼으로 '목록' 과 '수정' 화면으로 이동하며, Path 에 버전 마디(/서비스/v1.0/…)가 있는 API 에는 '버전 올리기' 버튼이 표시됩니다.
