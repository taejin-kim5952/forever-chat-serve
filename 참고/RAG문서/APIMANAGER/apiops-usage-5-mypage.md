# MY PAGE 화면

MY PAGE 는 로그인한 사용자 본인의 정보만 보여 주는 메뉴입니다.
MY API 에서 내가 등록한 API 를, MY 권한에서 내 서비스 권한을 확인하고 신청합니다.

## 내가 등록한 API 보기 (MY API)

질문: 내가 등록한 API만 보려면 / MY API가 뭔가요 / 내 API 진행 단계 / MY API에 API가 안 보여요

좌측 메뉴에서 'MY PAGE' 를 선택하면 'MY API' 화면이 열립니다. 내가 등록한 API 를 그룹 구분 없이 한 번에 봅니다.
위쪽 '진행 단계' 에는 내가 등록한 API 가 등록 · TB 배포 · 테스트 · 운영 배포 단계마다 몇 건인지 표시되고, 단계 아래 날짜는 그 단계가 가장 최근에 진행된 날입니다.
서비스 · 그룹 · 진행 단계를 고르고 검색어를 입력한 뒤 '검색' 버튼을 선택합니다. 서비스를 바꾸면 그룹 목록이 그 서비스의 것으로 바뀌고 목록이 다시 조회됩니다.
목록의 '진행 상태' 는 점 네 개로 등록 → TB 배포 → 테스트 → 운영 배포 순서를 나타내며, API 명을 선택하면 상세 화면으로 이동합니다.

MY API 에는 지금 권한이 있는 서비스의 API 만 표시됩니다. 권한이 만료된 서비스의 API 는 보이지 않습니다.

## 내 권한 확인 (MY 권한)

질문: 내 권한을 어디서 보나요 / MY 권한 화면 / 권한 상태 종류 / 권한이 만료됐어요

좌측 메뉴 'MY PAGE' 아래 'MY 권한' 을 선택합니다. 내 권한이 서비스 · 권한 그룹 · 사용기간 · 상태 · 요청일시 · 승인일시 순서로 표시됩니다.
상태는 신청 · 승인 · 반려 · 기간만료 네 가지이며, 검색 조건에서 상태별로 추려 볼 수 있습니다.

## 권한 신청과 연장 신청

질문: 서비스 권한은 어떻게 신청하나요 / 권한 신청 방법 / 권한 연장은 어떻게 하나요 / 연장신청 버튼이 없어요 / 사용기간은 어떻게 정하나요

**권한 신청** - 오른쪽 위 '권한 신청' 버튼을 선택하면 신청 팝업이 열립니다. 서비스와 권한 그룹을 고르고 사용기간을 입력한 뒤 '확인' 버튼을 선택합니다. 사용기간은 '3개월' · '6개월' · '1년' 버튼으로 종료일을 한 번에 채울 수 있습니다.

**권한 연장 신청** - 목록 오른쪽 '연장신청' 버튼은 승인 · 기간만료 상태의 권한에만 표시됩니다. 연장 신청 팝업에서는 서비스와 권한 그룹이 고정되고, 시작일은 기존 종료일 다음 날로 채워집니다. 종료일을 입력한 뒤 '확인' 버튼을 선택합니다.

권한 신청과 연장 신청은 운영 담당자의 승인이 끝나야 적용됩니다. 승인 전에는 상태가 '신청' 으로 표시됩니다. API 등록과 배포는 해당 서비스 권한이 있어야 가능하므로, 좌측 트리에 서비스가 보이지 않으면 먼저 권한을 신청합니다.
