# 이전 자료 — 프로젝트(packs)로 나누기 전의 기본 팩 문서

2026-10-07 에 `data/raw_docs/` 를 여기로 옮겼습니다. **지운 것이 아니라 보관**입니다.

## 왜 옮겼나

프로젝트를 쓰기 전에는 모든 자료가 `data/` 한 곳에 있었습니다. 지금은 `packs/<프로젝트>/`
로 나뉘어 있고, 여기 40건은 **어느 프로젝트에서도 쓰이지 않습니다.**

그런데 `data/` 는 프로젝트를 고르지 않았을 때의 **기본 팩**이라, 스크립트에 `--project` 를
빠뜨리면 이 문서들이 재료가 됩니다. 2026-10-06 에 실제로 그래서 **MCP 프로젝트에 API
Manager 문서로 만든 QA 60건이 들어갔습니다**(오류는 한 줄도 안 났습니다).

스레드 컨텍스트 버그는 고쳤지만, 재료 자체를 치워 두는 편이 확실합니다.

## 다시 쓰려면

필요한 파일을 골라 사용자 화면의 자료 올리기로 넣으면 됩니다. **프로젝트를 먼저 고르세요.**

`packs/api-manager/raw_docs/` 에 있는 5건(`apiops-usage-*.md`)은 이 40건을 다시 쓴
것입니다. 나머지 35건은 여기에만 있습니다.
