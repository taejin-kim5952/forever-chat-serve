# API 그룹(스펙/SPC) 등록

"API 등록(NEW)" 메뉴로 들어가면 나오는 첫 화면입니다. 개별 API(Method+Path)를 등록하기
전에, 그 API들이 속할 **그룹(스펙, SPC)**을 먼저 만드는 화면입니다.

## 그룹이란 무엇인가

여러 API가 같은 호스트/기본경로/서비스/버전을 공유할 때, 그 묶음을 "그룹"이라고 부릅니다.
예를 들어 "메시징 서비스"라는 그룹 하나를 만들어두면, 그 아래에 `GET /messages`,
`POST /messages` 같은 여러 API를 계속 추가할 수 있습니다. 그룹은 보통 한 번만 만들고,
이후 API 추가는 이 화면을 다시 거치지 않고 "API 등록" 화면에서 바로 합니다
([[api-등록]] 참고).

## 입력 항목

**기본으로 보이는 필수 항목**

| 항목 | 필수 | 설명 |
|---|---|---|
| 서비스 | O | 이 그룹이 속할 서비스 선택. 선택하면 왼쪽에 그 서비스의 기존 그룹 목록이 참고용으로 표시됩니다 |
| API 그룹 이름 | O | 목록/규격서에 노출되는 그룹 이름 |
| 설명 | X | 이 그룹이 어떤 API 묶음인지 한 줄 설명 |

**"전체보기"를 눌러야 나오는 항목** (대부분 기본값 그대로 써도 무방)

| 항목 | 필수 | 기본값 | 설명 |
|---|---|---|---|
| 호스트 | O | `openapis.kt.com` | API 서버 호스트 |
| 기본경로 | O | `/` | 이 그룹에 속한 모든 API 경로 앞에 공통으로 붙는 경로 |
| API 구분 | X | Public | Public/Private/Internal 중 선택 |
| 버전 | X | `V1.0` | |
| 스키마 | X | https | http/https |
| 테스트 BASEURL | X | (비움) | 비워두면 운영 호스트로 테스트 |
| BEAST G/W 사용여부 | X | 사용 안함 | |

## 그룹을 빠르게 만드는 방법 — YAML 등록

이미 갖고 있는 OAS 3.0(Swagger) 스펙 문서가 있다면, 헤더의 **"YAML 등록"** 버튼으로 그
YAML을 붙여넣거나 파일로 불러올 수 있습니다. YAML 하나 안에 여러 Path/Method가 있어도
전부 인식해서, [적용] 시 그룹 정보(이름/호스트/기본경로/버전)를 자동으로 채우고, 그
안의 API들도 함께 파싱해둡니다. 이후 그룹을 저장하면 파싱된 API들이 한 번에
`KOA_TB_API_DEF`로 등록되어, 그룹 하나와 API 여러 건이 동시에 만들어집니다.

(참고: 개별 API 하나에 템플릿을 적용해 빠르게 채우는 "템플릿으로 시작" 기능은 이 화면이
아니라 "API 등록" 화면에 있습니다 — YAML 등록은 그룹 단위, 템플릿은 API 단위 기능입니다.)

## 저장하기

저장 버튼("저장하고 API 추가하러 가기")을 누르면 확인 팝업이 뜨고, [저장]을 눌러야 실제로
저장됩니다. 저장에 성공하면 자동으로 "API 등록" 화면으로 이동하며, 방금 만든 그룹 아래에
바로 첫 API를 등록할 수 있는 상태가 됩니다.

## 이미 만든 그룹의 정보를 수정하려면

이 화면은 그룹 목록에서 직접 들어오는 게 아니라, "API 등록" 화면 헤더의 **"그룹 정보 수정"**
버튼을 통해 들어옵니다. 이 경우 화면 제목이 "그룹 정보 수정"으로 바뀌고, 기존 값이 폼에
채워진 상태로 열립니다. YAML 등록 버튼과 "다음 단계 안내" 배너는 이때는 의미가 없어
보이지 않습니다. 저장하면 새 그룹이 만들어지는 게 아니라 기존 그룹 정보가 업데이트되고,
다시 "API 등록" 화면(같은 그룹)으로 돌아갑니다.

## 자주 묻는 질문

**Q. 그룹을 나중에 다시 수정할 수 있나요?**
A. 네. "API 등록" 화면(그 그룹의 API 목록/등록 화면)에서 "그룹 정보 수정" 버튼을 누르면
이 화면이 기존 값을 채운 채로 열리고, 수정 후 저장하면 됩니다.

**Q. 호스트나 기본경로를 꼭 직접 입력해야 하나요?**
A. 기본값(`openapis.kt.com`, `/`)이 이미 채워져 있어 대부분 그대로 두어도 됩니다. 다른
값이 필요한 그룹만 "전체보기"를 펼쳐서 바꾸면 됩니다.

**Q. YAML 등록과 "템플릿으로 시작"의 차이는 무엇인가요?**
A. YAML 등록은 이 화면(그룹 등록)에서 쓰며, 문서 하나로 그룹+여러 API를 한 번에 만듭니다.
"템플릿으로 시작"은 "API 등록" 화면에서 API 한 건을 등록할 때, 자주 쓰는 값(예: 공통
요청/응답 필드)을 미리 채워주는 기능입니다.
