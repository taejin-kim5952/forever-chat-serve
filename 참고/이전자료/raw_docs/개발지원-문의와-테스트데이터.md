# 개발지원 문의와 테스트데이터 신청

개발 중에 필요한 지원을 요청하는 창구입니다. 문의 게시판과 테스트데이터 신청,
SDK 다운로드가 여기에 모여 있습니다.

## 화면 주소

| 기능 | URL |
|---|---|
| 개발지원 목록 | `/apidev/devsupport/devsupport/devSupportList.do` |
| 목록 데이터 | `/apidev/devsupport/devsupport/selDevSupportListAjax.do` |
| 등록 화면 | `/apidev/devsupport/devsupport/mvDevsupportReg.do` |
| 상세 보기 | `/apidev/devsupport/devsupport/mvDevSupportView.do` |
| 저장 | `/apidev/devsupport/devsupport/saveForum.do` |
| 담당자 목록 | `/apidev/devsupport/devsupport/selManagerListAjax.do` |
| 테스트데이터 신청 | `/apidev/devsupport/tdapply/testdataapply.do` |

개발지원 목록과 테스트데이터 신청 화면은 로그인 없이도 열립니다.

## 문의 등록

| 항목 | 설명 |
|---|---|
| 제목 | 무엇이 필요한지 한 줄로 |
| 분류 | 문의 유형(개발 환경, 연동, 데이터 등) |
| 내용 | 재현 방법, 오류 메시지, 대상 API |
| 첨부파일 | 화면 캡처, 로그 파일 |
| 담당자 | 지정하고 싶은 담당자가 있으면 선택 |

담당자 목록은 별도 조회로 가져옵니다. 담당자를 지정하지 않으면 분류에 따라 자동
배정됩니다.

## 작성자 표시 마스킹

목록에 나오는 작성자 이름은 뒤 두 글자가 `***` 로 가려집니다. 개인정보 노출을 줄이기
위한 처리입니다.

## 테스트데이터 신청

개발·검증에 쓸 시험 데이터를 요청하는 화면입니다. 어떤 시스템의 어떤 데이터가
필요한지, 언제까지 필요한지를 적어 신청합니다. 실데이터가 아니라 가공된 시험용
데이터가 제공됩니다.

## SDK 다운로드

연동용 SDK를 내려받는 경로(`/apidev/devsupport/sdkdwn/sdkdwn.do`)도 개발지원
영역에 있습니다. 언어별 SDK와 샘플 코드가 제공됩니다.

## VM 가이드

개발 VM 환경 사용 안내(`/apidev/devsupport/vmguide/devVmGuide.do`)도 같은 묶음에
포함됩니다.

## 자주 묻는 질문

**Q. Q&A와 개발지원 문의는 어떻게 다른가요?**
A. Q&A는 포털 사용법과 API 규격에 대한 질문, 개발지원은 개발 환경·테스트데이터·SDK
처럼 실제 개발 작업을 지원하는 요청입니다.

**Q. 문의를 올렸는데 답이 없습니다.**
A. 담당자 배정 상태를 상세 화면에서 확인하세요. 급한 건은 내용에 연락처를 적어
두면 담당자가 직접 연락합니다.

**Q. 테스트데이터에 실제 고객 정보가 들어 있나요?**
A. 아니요. 가공된 시험용 데이터만 제공됩니다. 실데이터 요청은 별도 승인 절차가
필요합니다.

**Q. 첨부한 로그 파일이 열리지 않습니다.**
A. 확장자와 용량 제한을 확인하세요. 파일 하나당 10MB 제한이 있습니다. 큰 로그는
필요한 구간만 잘라 올리세요.

**Q. SDK 버전이 오래된 것 같습니다.**
A. 다운로드 화면의 게시 일자를 확인하고, 최신 버전이 필요하면 개발지원 문의로
요청하세요.
