# 공통코드 체계

화면의 선택 목록(셀렉트박스)과 상태 표시는 대부분 공통코드 테이블
(`KOA_TB_COMN_CD`)에서 값을 가져옵니다. 코드 값은 **영문 접두사 + 4자리 숫자** 형태를
따릅니다.

## 코드 읽는 법

```
APIREG1030
└──┬──┘└─┬┘
   │     └─ 순번. 뒷자리가 클수록 진행된 단계
   └─ 코드 그룹. 어떤 업무의 코드인지
```

## 등록 상태 (`APIREG`)

| 코드 | 의미 | 화면 표시 |
|---|---|---|
| `APIREG1000` | 작성 중 | 임시저장 |
| `APIREG1010` | 등록 완료 | 등록됨 |
| `APIREG1020` | 검토/승인 진행 | 검토중 |
| `APIREG1030` | 공개 | 서비스중 |

**검색·규격서에 나오는 것은 `APIREG1030` 뿐입니다.** 이 한 줄이 "등록했는데 안
보인다"는 문의의 대부분을 설명합니다.

## 배포 상태 (`DEPLOY`)

| 코드 | 의미 |
|---|---|
| `DEPLOY1000` | 배포 신청 |
| `DEPLOY1050` | 승인 진행 |
| `DEPLOY1063` | TB 배포 완료 |
| `DEPLOY1065` | 운영 배포 대기 |
| `DEPLOY1070` | 배포 완료 |

## 회원 상태 (`MBRSTS`)

| 코드 | 의미 |
|---|---|
| `MBRSTS1020` | 정상 사용 |
| `MBRSTS4010` | 탈퇴/정지 |

## 코드로 관리되는 다른 항목들

공통코드 테이블에는 아래 항목의 선택지도 함께 들어 있습니다.

| 항목 | 화면에서 쓰이는 곳 |
|---|---|
| HTTP Method | API 등록의 Method 선택 |
| 데이터 타입 | 파라미터 설계의 타입 선택 |
| 파라미터 위치 | header / path / query / body |
| 컨텐츠 타입 | 요청 본문 형식 |
| 핸들러 종류 | Private API의 핸들러 선택 |
| API 구분 | Public / Private / Internal |
| 게시판 분류 | FAQ 카테고리, 문의 유형 |
| 검증 상태 | 검증 결과 표시 |

## Y/N 플래그

코드가 아니라 단순 `Y`/`N` 으로 관리되는 값도 많습니다.

| 필드 | 의미 |
|---|---|
| `USE_YN` | 사용 여부. `N` 이면 목록에서 제외 |
| `TMPLT_YN` | 템플릿 여부 |
| `SANDBOX_YN` | 샌드박스 테스트 허용 |
| `IMPORT_YN` | 외부에서 반입된 항목인지 |
| `BSTGW_YN` | BEAST 게이트웨이 사용 여부 |
| `ADMR_YN` | 관리자 여부 |
| `WRITER_YN` | 작성자 권한 여부 |
| `OBSERVER_YN` | 옵저버(조회 전용) 여부 |
| `STPLT_AGREE_YN` | 이용약관 동의 |
| `INDV_INFO_AGREE_YN` | 개인정보 동의 |

## 코드가 화면에 오는 경로

```
KOA_TB_COMN_CD (DB)
      │ 조회
      ▼
공통 서비스 (CmnService)
      │
      ▼
화면 셀렉트박스 / 상태 라벨
```

화면에는 코드 값(`APIREG1030`)이 아니라 코드명(`서비스중`)이 표시됩니다. 개발자
도구 네트워크 탭이나 API 응답에서는 코드 값 그대로 보입니다.

## 자주 묻는 질문

**Q. 선택 목록에 원하는 값이 없습니다.**
A. 공통코드에 등록되지 않은 값입니다. 운영자에게 코드 추가를 요청해야 합니다.
화면에서 임의로 추가할 수 없습니다.

**Q. 상태값이 숫자로만 보입니다.**
A. 코드명이 등록되지 않았거나 조회가 실패한 경우입니다. 화면 새로고침 후에도 같으면
공통코드 데이터에 문제가 있는 것입니다.

**Q. 코드 번호 사이가 비어 있습니다(1000, 1010, 1030...).**
A. 나중에 단계가 추가될 여지를 남긴 채번 방식입니다. 빈 번호에 의미는 없습니다.

**Q. `USE_YN = N` 으로 바꾸면 데이터가 지워지나요?**
A. 아니요. 목록·검색에서 제외될 뿐 데이터는 남습니다. 되돌리려면 다시 `Y` 로
바꾸면 됩니다.
