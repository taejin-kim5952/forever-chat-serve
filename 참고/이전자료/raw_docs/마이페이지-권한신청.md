# 마이페이지와 권한 신청

가입만 해서는 API를 등록할 수 없습니다. **어떤 시스템에 대해 무슨 일을 할 수 있는지**를
정하는 권한그룹을 신청하고 승인받아야 합니다. 그 신청을 하는 곳이 마이페이지입니다.

## 화면 주소

| 기능 | URL |
|---|---|
| 마이페이지 | `/apidev/mypage/mypageInfo.do` |
| 콘솔 | `/apidev/mypage/console.do` |
| 이전 화면 조회 | `/apidev/mypage/selBackViewAjax.do` |
| 셀렉트박스 데이터 | `/apidev/mypage/selboxAjax.do` |
| 권한 신청 등록 | `/apidev/mypage/autInsertAjax.do` |

## 마이페이지에서 하는 일

- **내 정보 확인·수정** — 이름, 회사, 연락처, 이메일
- **권한 현황 확인** — 현재 부여된 권한그룹 목록
- **권한 신청** — 필요한 시스템·권한그룹을 골라 신청
- **내가 등록한 API 조회** — 본인이 만든 API 목록

## 권한그룹이란

권한그룹(`autId`)은 "이 시스템에서 무엇을 할 수 있는가"의 묶음입니다. 두 가지 서로
다른 개념이 비슷한 이름으로 쓰이니 주의하세요.

| 구분 | 어디서 쓰나 | 의미 |
|---|---|---|
| **사용자 권한그룹** | 마이페이지 권한 신청 | 이 사람이 어느 시스템에서 무슨 작업을 할 수 있는가 |
| **API 권한그룹** | API 등록 화면의 `권한그룹` 항목 | 이 API를 어느 그룹이 호출할 수 있는가 |

마이페이지에서 신청하는 것은 앞의 것입니다. API 등록 화면에서 고르는 권한그룹은
호출 권한이며, 사람의 작업 권한과는 별개입니다.

## 신청 절차

```
① 마이페이지 접속 → ② 시스템 선택 → ③ 권한그룹 선택 → ④ 신청 사유 입력
      ↓
⑤ 신청 등록 → ⑥ 관리자 승인 대기 → ⑦ 승인 완료 → ⑧ 메뉴·시스템 목록에 반영
```

승인 전에는 신청한 시스템이 등록 화면의 시스템 목록에 나타나지 않습니다.

## 신청서 첨부

권한 신청 시 사내 양식 문서를 첨부해야 하는 경우가 있습니다. 기본 양식 파일명은
`authority.docx` 로 설정되어 있고, 마이페이지에서 내려받을 수 있습니다.

## 특수 권한

| 권한 | 설명 |
|---|---|
| **A/G 운영자 그룹** | 게이트웨이 배포·관리 전반. 권한 ID `94` |
| **옵저버(Observer)** | 조회 전용. 세션의 `observerYn` 이 `Y` 이면 등록·수정 버튼이 감춰짐 |
| **작성자(Writer)** | 자기 API 등록·수정. `writerYn` 값으로 판정 |
| **관리자(`admrYn`)** | 회원·공통코드 등 관리 기능 접근 |

## 자주 묻는 질문

**Q. 권한 신청을 했는데 언제 승인되나요?**
A. 관리자가 수동으로 처리합니다. 급하면 신청 사유에 담당자와 연락처를 적어 두면
확인이 빨라집니다.

**Q. 승인이 났는데도 시스템 목록에 안 보입니다.**
A. 세션에 담긴 권한 정보가 로그인 시점 기준이기 때문입니다. 로그아웃 후 다시
로그인하면 반영됩니다.

**Q. 여러 시스템 권한을 한 번에 신청할 수 있나요?**
A. 신청은 시스템 단위로 등록합니다. 여러 개가 필요하면 각각 신청하세요.

**Q. 권한을 반납하려면?**
A. 화면에 반납 기능이 없어 관리자에게 요청해야 합니다. 인사 이동 시에는 관리자가
일괄 정리합니다.

**Q. 옵저버인데 등록 버튼이 안 보입니다.**
A. 정상 동작입니다. 옵저버는 조회 전용 계정이므로 등록·수정·배포 버튼이 화면에서
감춰집니다. 작업이 필요하면 작성자 권한을 신청하세요.

**Q. 내 정보의 이메일을 바꾸면 알림도 그리로 오나요?**
A. 네. 배포 승인·반려 알림 메일은 회원 정보의 이메일 주소로 발송됩니다.
